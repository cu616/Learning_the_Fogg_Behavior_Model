# 福格行为实验室 v0.2.0

发布日期：2026-08-24

V0.2 是 Windows 与 Android 并行维护后的首个正式双平台版本。相较 V0.1 的早期简化界面，本版完成森林背景与深色半透明玻璃 UI 重构，并加入包含三类行为工作流的 Android 移动版。

## 主要变化

- 长期习惯：完整七步、多黄金行为、多微习惯方案、触控行为云与焦点地图。
- 一次性行为：明确下一动作、P / A / M 渐进诊断、返回栈、行动与诊断历史。
- 终止旧习惯：准备、拆解、P / A / M 对策、观察调整和替代行为。
- 跨平台：Windows 与 Android 共享 React、Rust、SQLite 和导入导出格式。
- 界面：森林背景、深色玻璃层级、七步语义色、按需理论笔记与本地背景替换。
- 本地优先：核心流程离线运行，不依赖 AI 或在线资源；Android 不声明 `INTERNET` 权限。

## 安装与签名说明

- Windows 安装包内含 WebView2 离线安装程序，目标电脑完成安装和使用核心功能时不需要联网。
- Windows EXE 与安装包没有商业代码签名证书，系统可能显示“未知发布者”；请核对 SHA-256。
- Android APK 使用 Android 调试证书并通过 APK Signature Scheme v2 校验，适合自行侧载测试，不用于应用商店。以后切换正式签名时，可能需要先导出数据并卸载调试签名版本。
- Windows 与 Android 各自保存本地数据，不会自动同步；需要跨设备迁移时使用完整 JSON 导出和导入。
