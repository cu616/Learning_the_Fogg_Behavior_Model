# 福格行为实验室 v0.3.0

发布日期：2026-08-25

V0.3 将协作者的孤独摇滚视觉分支合并回 V0.2 双平台产品。专业模式继续作为默认界面，用户可以在“数据与外观”中切换孤独摇滚模式；桌面端和 Android 端共享相同的三类行为工作流、SQLite 数据与离线能力。

## 主要变化

- 新增专业模式与孤独摇滚模式即时切换，主题偏好只保存在当前设备。
- 动漫主题覆盖桌面首页、移动首页、长期习惯、一次性行为与终止旧习惯工作台。
- 主题样式按需装载，切换主题不改变数据库、自动保存、日志或导入导出格式。
- 专业模式继续支持自定义本地背景；切换动漫主题不会删除原背景设置。
- 通过真实 Git 合并保留协作者分支历史，并补充主题资源来源与许可边界。

## 安装与签名说明

- Windows 安装包内含 WebView2 离线安装程序，目标电脑安装与使用核心功能时不需要联网。
- Windows EXE 与安装包没有商业代码签名证书，系统可能显示“未知发布者”；请核对 SHA-256。
- Android APK 使用 Android 调试证书并通过 APK Signature Scheme v2 校验，适合自行侧载测试，不用于应用商店。
- Android 应用不声明 `INTERNET` 权限；主题图片和行为模型资料均随安装文件离线提供。
- Windows 与 Android 各自保存本地数据，不会自动同步；跨设备迁移请使用完整 JSON 导出与导入。
