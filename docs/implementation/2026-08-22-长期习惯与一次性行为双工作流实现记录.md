# 长期习惯与一次性行为双工作流实现记录

- 日期：2026-08-22
- 数据库版本：5
- 当前导出格式：`fogg-lab-export-v3`

## 本轮完成范围

### 长期习惯设计

- 三栏工作台与左侧渐进式设计摘要；
- 一个愿望对应多个黄金行为，每个黄金行为支持多个独立微习惯分支；
- 行为集群云朵画布、可拖动 9×9 焦点地图、交互式能力链；
- 第一步只要求最终愿望，引导问题合并为非必填折叠区；
- 第四步按选中的简化方法条件展开，基线行为与可选扩展常驻；
- 第七步同时记录结果、感受和情境；
- 行为、配方、锚点、庆祝和肯定成功方式的本地个人库；
- 桌面语义双列、首页每行两张卡片与窄屏单列回退。

### 一次性行为

- 首页独立快速入口与双列任务卡片；
- 任务、完成标准和当前唯一下一动作的低负担捕获；
- 现在做、卡住、安排稍后三条路由；
- 严格 P→A→M 的渐进诊断，同时支持直接选择已知问题；
- P 的任务提示/干扰提示、A 的任务简化/干扰增阻、M 的继续/取消/委托/延期/重新协商；
- 每轮只保存一个主要调整并返回行动；
- 完成、取消、委托、延期和归档状态，无“失败”状态；
- 诊断轮次与行动事件历史；
- 一次性行为转为长期习惯时保留原任务背景。

### 画布与数据生命周期补充

- 首页为长期行为设计和一次性行为提供永久删除；前端先展示名称并二次确认，后端删除前自动创建完整保护快照；
- 第二步行为卡片按内容给出紧凑初始尺寸，右下角可拖动调整宽高，尺寸随位置一起保存在本地；
- 第三步焦点地图以 −4～4 显示九级坐标，突出横纵零轴，并兼容旧版 1～9 存储数据；
- 七步标题、主要引导和首页区域加入离线符号图标及分步主题色，保留完整文字标签。

### 黄金行为层级与焦点地图补充

- 选中黄金行为时不再自动创建同名微习惯分支：黄金行为是父级方向，微习惯方案只在进入第四步时按需创建；
- 新微习惯分支使用“微习惯方案 N”作为独立名称，并可在左侧摘要中重命名，避免父子层级出现两次相同标题；
- 第四步之前，左侧在黄金行为下显示“第四步再设计微习惯”，并隐藏“添加微习惯方案”入口；
- 焦点地图的整个第一象限为黄金行为候选区，横纵零轴加粗，并在影响高、可行性高的正方向绘制箭头；
- “影响低/高、难以做到/容易做到”贴近对应坐标轴放置，刻度也移到零轴附近；
- 左侧摘要的愿望、黄金行为、微习惯方案和编辑动作增加轻量符号图标，强化信息层级但不替代文字标签。

### 删除错误修复与入口审计

- 删除前保护快照的文件名仍保留 `before-delete` 语义，但 `backup_record.backup_type` 改为数据库允许的 `full`，修复 `CHECK constraint failed`；
- 首页长期行为设计与一次性行为继续使用名称确认和完整保护快照；
- 第二步行为卡片可删除，第三步已选黄金行为可从摘要或地图卡片中移除选择；
- 当前微习惯方案增加永久删除，删除前创建完整保护快照，并级联移除该方案的设计与实践记录；
- 第五步锚点候选、第六步庆祝候选增加删除入口；
- 第二、第五、第六步展开的个人行为、锚点、庆祝和肯定语言库增加就地删除，并继续保留数据管理页的统一删除入口；
- 备份列表增加删除；后端只允许删除规范化路径位于应用备份目录内的快照文件；
- 配方版本、实践日志和诊断历史作为回溯记录不提供普通单条删除，可随所属微习惯方案或整个项目删除。

### 渐进式信息密度与理论笔记侧栏

- 首页移除品牌副标题，把“新建长期设计”输入和按钮移到“长期习惯设计”标题行，与一次性行为入口保持一致；
- 移除左侧摘要副标题、黄金行为下的流程预告及行为云朵空状态说明，避免同一操作被多处文字重复解释；
- 第二步的书中配方和个人灵感库紧邻添加行为输入；书中配方按身份折叠，提取浮层压缩为一行“候选行为 + 输入 + 操作”；
- 行为卡片到愿望云朵的连线加粗，箭头停在云朵边缘而不是被云朵遮挡；
- 第四步能力链只保留一次主要操作引导；基线行为与可选扩展使用图标和并排结果卡，左侧摘要中的基线、扩展、锚点和庆祝也采用两列；
- 第五步锚点模板与个人锚点库、第六步庆祝库与肯定语言库分别融合进当前输入卡片；字段标题使用离线符号和更强字重；
- 第六步自然度与成功感改为行内紧凑选择；第七步感受和情境合并为默认收起的可选区；
- 第七步底部主动作改为“完成本轮，回到首页”；
- 七步右栏改为“福格模型笔记”，从 `docs/福格行为模型-右侧提示笔记.md` 交叉匹配精炼理论；删除重复的当前编辑对象提示；
- 一次性行为工作台增加随捕获、诊断、P/A/M 和行动页面变化的理论笔记栏，并强化字段标题字重与关键图标；
- 原始右侧提示笔记保持不变，前端映射单独保存在 `app/src/foggNotes.ts`。

### 按需展开首页、覆盖式参考库与完整章节

- 第七步按钮改为“结束本次记录，回到首页”，它只结束当前操作，不改变习惯或分支状态；
- 每次实践保存为独立 `branch_practice_event`，包含结果、感受、情境、发生时间和配方版本；非成功结果关联独立诊断记录；
- 实践、诊断和配方版本全部进入完整备份、全量 JSON 导出和单项目导出；界面当前加载最近 200 条实践记录，但数据库不会因下一次反思而覆盖上一条；
- 首页平铺状态筛选改为单个下拉框；长期习惯和一次性行为分区默认收起，只显示数量与“展开管理”；
- 展开后的项目卡片使用 `auto-fill + minmax(235px, 1fr)`，宽桌面通常每行 4 张，随宽度回退 3、2、1 张；
- 步骤内参考库的内容区改为绝对定位浮层，展开时覆盖后续内容，不再推动下方卡片；浮层内部保持滚动和身份分类折叠；
- `app/src/foggNotes.ts` 按原始笔记重建第一至第七章完整数据；七步按章节绑定，一次性行为按当前 P/A/M 路径组合多个章节。

### 紧凑操作与删除确认偏好

- 首页分区只显示展开/收起图标；数据管理、返回、新建、编辑、复制、归档和删除等高频动作改为带悬停说明与无障碍名称的紧凑图标；
- 输入框旁的新建和添加动作缩为加号或“添加”，不再重复“长期设计”“一次性行为”等上下文已经表达的对象名称；
- 数据管理增加“删除前输入完整名称”开关，默认关闭；永久删除仍保留一次确认并自动创建完整保护备份；
- 流程中的上一步、下一步和含义可能模糊的决策按钮保留文字，避免为追求简短而损失可理解性。

### 聚焦式工作台与按需支持面板

- 长期工作台默认只显示中央当前步骤；设计摘要和福格模型笔记均由顶部图标按需打开；
- 一次性行为工作台采用同一结构，并把“明确动作—按需诊断—返回行动”固定在中央顶部作为紧凑路径导航；
- 左侧摘要仅保留愿望、当前方案、当前下一动作和最近调整等定位结果，不再长期占据画布；
- 右侧理论笔记以覆盖抽屉出现，打开时不改变中央内容宽度和滚动位置；支持遮罩点击、Esc 关闭、焦点进入、Tab 约束和关闭后焦点回收；
- 笔记章节改为单项手风琴，默认仅展开首条最相关理论；
- 中央标题使用步骤强调线建立第一阅读目标，顶部流程为第二目标，摘要、笔记和历史为第三目标；
- 工作台普通表单容器移除部分边框、阴影和浅色底，以 16～32 像素的间距层级完成分组；
- 新增 `DESIGN.md` 与 ADR-0021，后续 Agent 可直接检索界面设计语言和决策理由。

- 右侧笔记手风琴取消章节与单元小字，默认仅展开首个相关知识点；

### 中性骨架与七步协调色谱

### 一次性诊断逐段展开

- P、A、M 解决页改为“确认对象或决定—选择方法—写下具体调整—决定下一步”的逐段展开，未来字段不再一次性平铺；
- “安排稍后做”已经确定进入任务提示路径，直接选择开始信号，不再重复询问提示对象和问题类型；
- P 改名为“设计开始信号”，并明确说明软件只保存逻辑提示，不会自动弹出提醒；计划时间和地点只在相关方法下出现；
- A 补齐“明确唯一下一动作”，任务侧、干扰侧与 M 均增加“其他方法”，选择后必须写明具体做法；
- 最终卡片由“调整后返回行动”改为“这次调整后怎么走”，只负责保存本轮调整并选择现在行动、稍后行动或再次诊断，不再呈现为回执；
- 最低动机测试只在降低任务难度时出现；回答“还要再缩小”后不会允许提前完成本轮调整；
- 新增 ADR-0024；沿用既有诊断轮次字段、历史记录、备份与离线存储，不需要数据库迁移。
