# ADR-0031：通透型森林玻璃材质阶梯

- 状态：已被 ADR-0032 替代
- 日期：2026-08-23
- 替代：ADR-0030
- 被替代：ADR-0032

## 背景

ADR-0030 直接采用了 WeTab 稳定 Glass Card 的约 70% 黑色和约 60% 黑色输入层。实际使用中，中央工作面、项目卡和文本输入框接近纯黑，森林背景几乎不可见；左侧约 40% 黑色状态栏反而呈现出更协调的通透度。

本项目是长时间使用的行为设计工具，而不是浏览器启动页。需要保留 WeTab 的角色化分层思想，但透明度应根据本项目的连续工作面和背景图重新校准。

## 决定

1. 以左侧状态栏的约 40% 黑色为视觉基准，建立连续阶梯：
   - 森林背景暗层：20%。
   - 首页 Dock 与分类承托面：26%。
   - 左侧状态栏和普通按钮：40% 黑色。
   - 中央工作面、首页项目卡：48%。
   - 悬停按钮：52% 黑色。
   - 理论抽屉、参考库和模态浮层：68%。
   - 文本输入不再叠加黑色，而是在所在工作面上使用约 8% 的中性亮色叠层，聚焦时提高到约 12%。
2. 中央工作面只比状态栏更稳定一档，不再以近纯黑表面完全遮住背景。背景依靠模糊和暗层退后，而不是依靠高不透明黑色消失。
3. 输入框在深色工作面上改用中性亮色叠层，使其最终灰度观感接近状态栏；聚焦时只小幅提亮并增强边界，避免黑色透明层叠加后形成黑洞状块面。
4. 浮层继续使用较深材质，因为它们需要盖住底层并承载长文字。这一稳定度不能扩散到常驻工作面。
5. 保留 ADR-0030 的圆角、描边、阴影、语义色、离线背景和减少透明度降级规则。

## 理由

透明度差异只有在表达层级时才有价值。把常驻区域压到 70% 黑色会牺牲背景氛围，却没有增加新的信息层级。以状态栏为基准建立窄而连续的阶梯，可以让页面更安静、一致，并通过浮层的单独深色保留必要的阅读稳定性。

## 影响

- 首页和三类行为工作台整体变得更明亮、更通透。
- 输入框不再接近纯黑，聚焦状态仍可通过描边和小幅加深识别。
- 森林背景会更明显，因此正文对比度和复杂背景区域需要持续做视觉检查。
- 不改变业务逻辑、数据结构、本地存储和离线能力。

## 备选方案

### 所有角色统一为 40% 黑色

会让中央工作面、状态栏和输入失去层级，拒绝。

### 只调亮输入框

不能解决中央工作面和项目卡遮挡背景的问题，拒绝。

### 更换为更亮的背景图片

只改变素材，不能修复材质本身过重的问题，拒绝。
