# ADR-0033：本地自定义背景图片

- 状态：已接受
- 日期：2026-08-23
- 补充：ADR-0028、ADR-0030

## 背景

应用已内置森林风景作为离线默认背景。用户希望保留默认图，同时可以导入自己的风景或其他图片，并要求个人数据继续保持本地优先。

## 决定

1. 接受 JPG、PNG、WebP，单张上限 20 MB。
2. 图片以 Blob 存入应用 WebView 的本地 IndexedDB，不发送网络请求，也不写入行为数据库。
3. 启动时先显示内置森林图，再读取本地偏好并替换；读取失败时安全回退到默认图。
4. 数据管理页提供“选择图片”和“恢复默认”。自定义背景属于外观偏好，不随行为数据 JSON 备份导出。
5. 运行时只用本地 Object URL 显示图片，替换或恢复时释放旧 URL。

## 理由

IndexedDB 适合保存比 localStorage 更大的二进制图片，无需增加 Rust 依赖或把大文件转成 Base64。把外观偏好与行为数据库分离，也避免背景图片显著放大习惯备份。

## 影响

- 功能完全离线，不改变现有行为数据结构。
- 清理 WebView 本地站点数据会清除自定义背景，但不会影响 SQLite 中的行为数据。
- 若未来要跨设备同步外观，需要另行决定导出格式与隐私边界。

## 备选方案

### 将 Base64 存入 localStorage

容量小且配额失败难以预测，拒绝。

### 将图片写入行为数据库或 JSON 备份

会放大高频备份并混合外观与行为数据，拒绝。
