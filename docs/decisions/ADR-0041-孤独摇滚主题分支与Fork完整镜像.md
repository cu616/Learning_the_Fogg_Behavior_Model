# ADR-0041：孤独摇滚主题分支与 Fork 完整镜像

- 状态：已接受
- 日期：2026-08-24
- 关联：[ADR-0036](./ADR-0036-孤独摇滚主题视觉重构.md)、[ADR-0040](./ADR-0040-安装包与签名策略.md)

## 背景

孤独摇滚主题版最初从较早的 `main` 提交创建，之后作为 Codex 本地分支持续开发。远程仓库现有 `fogg_Bocchi-the-Rock` 分支和用户的 GitHub Fork 都只是 `main` 的副本。用户明确要求不合并后续 `main`，把当前孤独摇滚主题版作为独立项目完整覆盖到这两个远程目标，并保留克隆后可直接还原主题所需的本地资产。

## 决定

1. `cu616/Learning_the_Fogg_Behavior_Model` 的 `main` 保持不变。
2. 当前孤独摇滚主题版完整覆盖到原仓库的 `fogg_Bocchi-the-Rock` 分支。
3. 当前孤独摇滚主题版同时完整覆盖到 `Praying1213/Learning_the_Fogg_Behavior_Model` Fork 的默认 `main` 分支。
4. 两个目标都以当前孤独摇滚主题版提交为独立历史终点，不合并远程 `main` 的 v0.2.0、知识库发布提交或后续产品结构。
5. `app/public/themes/` 下运行时使用的图片、标志和来源说明随独立版本提交，保证克隆后界面资源完整；构建缓存、工具链、安装包、APK、数据库和签名材料仍不进入 Git。
6. 覆盖远程时使用带预期远程提交哈希的 `--force-with-lease`，只更新指定分支，避免误触其他分支或覆盖并发改动。

## 理由

- 孤独摇滚主题版已经形成独立的页面框架、视觉语言、说明书、交互逻辑和移动端适配，不再作为原版的增量补丁维护。
- 保持 `cu616/main` 不变，可以继续保留原版；动漫分支和个人 Fork 分别承担独立版本与个人镜像。
- 完整提交运行时主题资源，避免克隆仓库后出现人物背景缺失。

## 影响

- 孤独摇滚主题版当前版本号继续为 `0.1.1`，不继承远程原版的 `0.2.0` 版本号。
- 原版在分支创建后新增的 `MobileApp.tsx`、发布文档和完整知识库不会进入孤独摇滚主题版，除非未来单独选择移植。
- 两个目标分支会从远程原版历史分叉；之后应在孤独摇滚主题分支上独立提交，不把它直接合并回原版 `main`。

## 备选方案

### 合并远程 main 后再上传

会引入用户不需要的原版后续结构，并产生大量双向冲突，不采用。

### 只上传主题代码、不上传运行时素材

克隆后无法还原当前界面，不符合完整镜像要求，不采用。
