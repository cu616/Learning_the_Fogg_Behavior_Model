# ADR-0022：常驻设计状态栏与湖绿工作面

- 状态：已接受
- 日期：2026-08-22

## 背景

ADR-0021 将左右支持信息都改为默认关闭的覆盖面板，成功释放了中央宽度，但也使用户无法一边设计、一边对照已经形成的愿望、黄金行为、基线行为和配方。左侧内容实际不是偶尔阅读的“摘要”，而是七步流程持续生长的设计状态。与此同时，纯白中央工作面与接近纯白的窗口背景色差过小，层次仍依赖边框，长时间观看也显得过亮。

右侧福格模型笔记的每条内容还显示章节来源。笔记已经按当前步骤交叉匹配，章节编号不帮助当前检索，反而增加一层低价值文字。

## 决定

1. 左栏正式命名为“设计状态”，宽桌面默认常驻并可收起；用户操作中央区时可以持续对照已形成的设计结果。
2. 左栏不使用覆盖抽屉，不遮挡中央操作；当可用宽度不足时才降级为覆盖面板。中央仍保持主要宽度和第一阅读层级。
3. 左栏以“最终愿望—黄金行为与方案—当前方案结果—配方与状态”的顺序组织，只显示已经形成的内容。分区使用留白、短标签和一条状态轨道，减少浅色卡片堆叠。
4. 一次性行为采用相同关系：左侧常驻显示当前下一动作与最近调整，中央顶部保留三段流程导航。
5. 右侧笔记继续作为按需覆盖抽屉，但取消章节、单元和来源小字；手风琴只显示知识点标题，展开后显示精炼内容。
6. 全局颜色改为浅湖绿画布、雾白工作面和深青蓝操作色。窗口底层不使用纯白；纯白仅用于少数需要抬升的交互卡片。
7. 七步中央区继续按唯一主任务重构：可选解释和历史渐进披露，普通字段以间距分组，地图与行为云朵获得更大实际操作面积，第七步首屏优先本次记录。
8. 配色、左栏展开与笔记开合只改变前端界面状态，不修改用户行为数据、日志结构或离线策略。

## 理由

- 设计状态是工作流的持续产物，查看频率高于理论笔记，适合常驻而不是按需覆盖。
- 左栏安静常驻、右栏按需覆盖，能同时满足“边看边做”和“中央操作优先”。
- 非纯白画布与雾白工作面通过表面色差建立层次，可减少边框和阴影使用。
- 章节编号属于书籍导航，不属于软件当前知识点的必要内容。
- 保留系统字体和本地 SVG，确保核心流程继续完全离线。

## 影响

- ADR-0021 中“左侧默认收起并以辅助面板出现”的决定由本 ADR 替代；右侧覆盖抽屉和三层阅读目标继续有效。
- ADR-0018 中“理论笔记显示章节映射”的展示形式由本 ADR 调整，但原始笔记内容和交叉匹配逻辑不变。
- `DESIGN.md`、全局色彩令牌、长期与一次性工作台布局、七步页面密度和响应式规则同步更新。
- 数据库、备份、导出、日志和正式 EXE 的离线运行方式不变。

## 备选方案

### 左栏继续使用覆盖抽屉

未采用。它适合低频资料，却不适合用户需要边操作边核对的主状态。

### 恢复原来的固定三列

未采用。右侧理论长文本会再次与中央任务争夺宽度和注意力。

### 使用纯白工作面并加深全部边框

未采用。会重新造成卡片堆叠感，也无法缓解整个窗口过白的问题。
