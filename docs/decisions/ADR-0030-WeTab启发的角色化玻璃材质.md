# ADR-0030：WeTab 启发的角色化玻璃材质

- 状态：已接受
- 日期：2026-08-23
- 替代：ADR-0029

## 背景

ADR-0029 将应用整体改为森林背景上的深色 Fluent 表面，解决了白色卡片与背景割裂的问题。但导航、中央工作面、状态栏和内部卡片仍使用近似的材质强度，层级不够明确，也没有充分呈现用户希望参考的 WeTab 式沉浸感。

项目已对 Microsoft Edge 商店发布的 WeTab 2.2.42 扩展进行离线静态研究，校验了 CRX3 签名和扩展标识，并从其样式包提取了可复核参数。研究只用于理解材质角色和数值，不复制扩展代码、图片或品牌资产。

## 决定

1. 使用“角色决定材质”的体系，而不是让全部区域共享一种透明度：
   - 首页顶栏和分类承托面使用 Dock 材质：约 30% 黑色、20px 模糊、16% 白色描边、24px 外层圆角和柔和环绕阴影。
   - 中央工作面、参考库弹层和理论抽屉使用稳定 Glass Card：约 70% 黑色、10% 白色描边、12px 圆角和短距离阴影；仅最外层使用模糊。
   - 左侧行为状态栏使用 Sidebar 材质：约 40% 黑色、40px 模糊并适度提高饱和度、16px 圆角。
   - 输入与普通控件静止时使用约 60% 黑色，聚焦时提高到约 70%，描边从 10% 白色提升到 20%，状态过渡约 100ms。
   - 工作面内部的普通内容卡片不重复模糊，仅使用低强度亮色叠层、单像素边界和轻阴影。
2. 森林图继续作为本地离线底图，并加约 30% 黑色暗层；不下载在线壁纸，不让背景参与状态表达。
3. 文字采用系统中文无衬线字体栈，正文基线 14px、辅助文字不低于 12px；主要输入和关键卡片使用 16px，标题按语义层级提升。字体只设常规和半粗两个权重角色。
4. 七步流程和三类行为的语义色继续用于步骤定位、图标、选中状态和主要操作，不能大面积染色或破坏深色表面的文字对比度。
5. 必须支持 `prefers-reduced-transparency` 和 `prefers-reduced-motion`。减少透明度时各角色回退为不透明深灰表面；低性能或嵌套区域不叠加模糊。

## 理由

WeTab 的视觉效果来自不同层级各自承担明确职责，而不是单一透明度。把 Dock、Card、Sidebar 和 Control 分开后，首页更轻，中央工作面更稳定，左侧状态更安静，输入只在用户意图出现时增强。该结构符合“一个主角，其余支持”和“静止时安静”的设计原则。

## 影响

- 全局材质令牌、圆角、阴影、输入焦点和字体层级统一调整。
- 页面结构、行为数据、本地存储和离线能力不变。
- 背景模糊会增加少量 GPU 开销，因此只允许出现在角色表面的最外层，并提供减少透明度回退。
- 后续新组件必须先确定其表面角色，再选择对应令牌，不得自行添加近似透明度。

## 备选方案

### 完整复制 WeTab 的代码和资源

存在版权、品牌和维护风险，也与本项目功能结构不同，拒绝。

### 所有卡片统一使用 70% 黑色

会失去前后层级，且内部卡片堆叠后过重，拒绝。

### 保留 ADR-0029 的无模糊表面

性能更稳定，但无法实现用户确认的沉浸式材质方向；本方案通过角色限制和降级模式控制性能风险。
