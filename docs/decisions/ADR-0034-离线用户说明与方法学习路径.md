# ADR-0034：离线用户说明与方法学习路径

- 状态：已接受
- 日期：2026-08-23

## 背景

七步、`B = MAP`、能力链、锚点和庆祝等概念已经被实现成软件工作流，但没有读过《福格行为模型》的用户仍可能不知道为什么先改提示、为什么要把行为变小，或者为什么一次没有行动不等于失败。只在字段旁边放理论摘要，不足以建立一套可迁移的思考方法。

## 决定

1. 提供一份可独立阅读的中文用户说明书，定位为“不读原书也能开始正确设计行为”，而不是原书摘要或学术解读。
2. 说明书按“三条心法—选择工作流—跟做示例—现实诊断—常见误区—数据安全”组织，先帮助行动，再提供术语索引。
3. 软件内增加常驻“使用说明”入口，内容完全离线，可以随时返回首页；不将教程变成创建项目前的强制步骤。
4. 说明必须同时覆盖长期习惯、一次性行为和终止旧习惯，并用一个连续案例说明每次要做的决定。
5. 说明的语气继续遵守无评判原则：不使用“缺少自律”、“打卡断了”或“失败”作为诊断；没有发生的行为统一视为对设计的新信息。
6. 严重成瘾、进食障碍、自伤或可能伤害他人的情况，明确提示寻求合格专业支持，不把本软件描述为替代性治疗。

## 理由

- 工具能告诉用户现在填什么，说明书才能帮助用户把方法迁移到软件外的真实情境。
- 按问题和示例组织比按书籍章节组织更适合零基础用户。
- 可跳过的离线指南不会延长核心路径，也不会建立网络依赖。

## 影响

- 新增 `docs/福格行为实验室-用户说明书.md`。
- 前端新增离线“使用说明”页面和首页入口。
- 本决定不改变用户数据、SQLite 结构、备份、导入导出或三类工作流。

## 备选方案

### 只提供原书章节链接

用户仍需先完成大量阅读才能开始，也不能保证离线可用，拒绝。

### 首次启动强制教程

会把帮助内容变成新的行动门槛，也不适合已经熟悉方法的用户，拒绝。

### 复制原书的长篇内容

这既不是用户说明的最佳结构，也不符合版权边界，拒绝。
