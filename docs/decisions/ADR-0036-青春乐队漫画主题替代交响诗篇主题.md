# ADR-0036：青春乐队漫画主题替代交响诗篇主题

- 状态：已接受；远程完整镜像范围由 [ADR-0041](./ADR-0041-独立动漫分支与Fork完整镜像.md) 调整
- 日期：2026-08-23
- 替代：[ADR-0035](./ADR-0035-动漫IP视觉主题与可替换资产层.md)

## 背景

《交响诗篇》浅青色主题仍保留后台软件的卡片、浅色工作面和大面积空白；官方群像被裁成横条，角色与业务区并排，使动漫人物像后贴装饰。首页有动漫图，进入工作台后又回到普通表单界面，无法形成完整的二次元产品体验。用户明确要求全部更换动漫元素，并允许视觉规范不完全遵循早期 README。

## 决定

1. 停止在代码中使用《交响诗篇》资产和青绿机甲主题；旧资产暂留独立目录以便追溯。
2. 动漫版本改用《孤独摇滚！》动画官网提供的后藤一里、伊地知虹夏、山田凉、喜多郁代透明立绘。运行时只读取本地副本，不访问官网。
3. 视觉语言改为青春乐队杂志与漫画拼贴：粉、黄、浅蓝、黑四色，粗黑描边、错位硬阴影、半调网点、斜向色带和非对称人物站位；取消玻璃、柔和渐变和层层圆角卡片。
4. 首页以四人乐队构图形成主海报；“继续上次的设计”使用一个漫画主格和两个编辑清单；三类工作流保持平面目录与连续项目行。
5. 项目页取消常驻左栏，改为“顶部状态票据—中央漫画章节—右侧角色旁白”。状态结果横向排列，人物与台词随当前流程和步骤切换。
6. 角色台词用乐队排练作比喻解释当前方法，但不扮演监督者、不评价完成率，也不把暂停、中断或重新设计描述为失败。
7. 标题使用本机方正姚体作为离线展示字体，正文继续使用 Noto Sans SC / 微软雅黑。产品名约 34px，页标题约 28–32px，项目标题约 19px，正文 17px，控件不小于 16px，辅助信息不小于 14px；不使用微型英文眉题配巨大中文标题。
8. 第二步行为集群和第三步焦点地图不再用灰色大画布等待用户理解；没有条目时压缩高度并直接说明下一动作，有条目后再恢复完整工作空间。说明书中的并列教学卡改为错位漫画时间线，避免同规格四卡模板。
9. 不改变本地优先、七步主流程、三类行为数据结构、无羞耻反馈和离线可用边界。

## 理由

- 四位角色的官方透明立绘适合参与排版，不需要裁海报或保留官网说明文字。
- 粗线漫画语言与粉黄蓝配色能覆盖首页和工作台组件，比“浅色后台 + 角色贴图”更完整。
- 角色旁白把动漫语境与福格方法连接起来，同时保持反馈中性。
- 将主题作为最后载入的独立 CSS 层，未来可以整体移除或替换。

## 影响

- 新增 `app/src/kessokuTheme.css`、`CharacterCue.tsx` 和 `app/public/themes/kessoku/` 主题素材层。
- `App.tsx` 和三类工作台增加角色站位与步骤台词，不改变数据调用、保存和路由。
- `animeTheme.css` 暂留早期实验记录，由新主题覆盖；稳定后可单独清理。
- 顶部设计状态增加可点击的七步进度带，替代没有信息的横向空白；第 2、3 步空状态与说明书终止旧习惯章节同步采用新的编辑式排版。

## 备选方案

### 继续细调《交响诗篇》浅色主题

无法解决 IP 视觉与后台框架割裂的问题，拒绝。

### 只替换首页人物

工作台仍会在进入后失去动漫感，体验断裂，拒绝。

### 使用生成式动漫人物

用户已明确拒绝 AI 生成角色，且会削弱原作作画辨识度，拒绝。
