# ADR-0032：深色工作台的语义色锚点

- 状态：已接受
- 日期：2026-08-23
- 替代：ADR-0031

## 背景

通透材质调整后，工作台的常驻表面与森林背景更加协调，但出现三类局部冲突：左侧微习惯结果卡仍使用约 54% 白色，成为突兀的亮块；七步主题色沿用浅色界面时期的暗色值，在深色工作面上缺乏定位力；焦点地图的黄金行为候选区仍是大面积近白浅绿，与周围深色坐标纸反差过强。

用户希望淡主题色有适度承托，而不是直接贴在黑色背景上，同时也明确指出频繁使用彩色卡片会造成审美疲劳。

## 决定

1. 七步主题色改为适合深色界面的较高明度、较低饱和度色阶，保证小字号主题文字在深灰工作面上具有可见性。
2. 主题色只在三个“语义锚点”使用淡色承托：每页唯一的步骤标题区域、左侧当前设计状态中的紧凑结果卡、焦点地图中被选择或进入候选范围的行为。
3. 步骤标题使用从约 14% 主题色向透明过渡的单次横向底层，而不是整块纯色卡。图标继续使用约 18% 主题色承托。
4. 左侧基线、可选扩展、锚点和庆祝卡由约 54% 白色改为约 9% 白色叠层，并加入低对比单像素边界。
5. 黄金行为候选区改为约 5%–13% 的低饱和绿色透明渐变；坐标网格使用低对比透明线。绿色只表达候选语义，不把第一象限变成亮色主角。
6. 高明度主题色只用于文字、图标和边界。主要按钮与当前步骤圆点使用由主题色和深色底混合得到的动作色，确保白色按钮文字具有足够对比度。
7. 普通表单、历史、理论笔记和非关键卡片不得新增主题色底，以防彩色承托泛滥。

## 理由

主题色的职责是帮助用户定位当前步骤，而不是装饰全部内容。只在少数语义锚点提供淡色承托，可以让颜色在深色背景上被看见，同时维持中央任务的单一视觉主角。大面积候选区降低明度后，坐标轴、行为卡与象限含义能按正确顺序被阅读。

## 影响

- 七步色谱整体更明亮，但仍保持协调的灰度和饱和度。
- 左侧状态卡不再出现灰白块面。
- 焦点地图第一象限与其余象限重新进入同一暗色材质体系。
- 不改变工作流、数据结构、本地存储或离线能力。

## 备选方案

### 每个小标题都增加彩色卡片

会产生重复图案和视觉疲劳，拒绝。

### 只提高主题色饱和度

容易产生霓虹感，且不能解决浅色状态卡和黄金象限的问题，拒绝。

### 完全取消步骤色

会丢失七步流程的空间定位线索，拒绝。
