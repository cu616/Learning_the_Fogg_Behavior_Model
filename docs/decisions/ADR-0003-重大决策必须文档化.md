# ADR-0003：重大决策必须文档化

- 状态：已接受
- 日期：2026-08-21

## 背景

项目将由用户和多个后续 AI Agent 长期协作。只存在于聊天上下文中的决定容易丢失、被误解或被重复讨论。

## 决定

所有显著影响产品方向、工作流、数据、技术架构、隐私、安全或用户体验的决定，都在 `docs/decisions/` 中使用 ADR 记录。

每份记录至少包括：

- 背景；
- 决定；
- 理由；
- 影响；
- 未采用或待评估方案；
- 状态和日期。

如果决定改变，保留旧 ADR，并用新的 ADR 标明替代关系。

## 理由

- 为后续 AI Agent 提供稳定上下文；
- 减少重复决策和方向漂移；
- 让用户能够审查重要取舍；
- 使产品、代码和文档之间保持一致。

## 影响

- 实施重大改动前需要先检查现有 ADR；
- 文档维护成为开发流程的一部分；
- 小型、可逆且不影响架构的实现细节不必单独建立 ADR。
