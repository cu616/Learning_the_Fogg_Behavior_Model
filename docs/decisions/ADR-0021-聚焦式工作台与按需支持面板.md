# ADR-0021：聚焦式工作台与按需支持面板

- 状态：已接受
- 日期：2026-08-22

## 背景

长期习惯与一次性行为工作台都长期并列展示左侧摘要、中央表单和右侧理论笔记。三个区域拥有相近的卡片密度、文字量和边框强度，中央当前任务因而不再是视觉主角。即使单个模块内容正确，用户仍需要在三列文字之间判断先看哪里。

现有 ADR-0018 已要求渐进披露，ADR-0019 已在参考库中采用覆盖浮层；这次需要把相同原则提升到工作台整体布局，并为第一、第二、第三阅读目标建立稳定顺序。

## 决定

1. 长期习惯与一次性行为统一采用“聚焦式工作台”：中央当前步骤是唯一永久主内容，宽桌面占可用区域约三分之二以上。
2. 左侧摘要改为默认收起的辅助定位面板。打开时只展示已经形成的结果和最近状态，不展示流程预告；窄窗口中以覆盖面板出现。
3. 右侧福格模型笔记改为默认关闭的覆盖式抽屉，不再挤压中央内容。抽屉支持遮罩点击、关闭按钮、Esc 关闭、焦点进入与关闭后焦点回收。
4. 一次性行为的三段路径从左栏移到中央区顶部，作为第二阅读目标；左栏只保留当前下一动作与最近调整。
5. 理论笔记使用手风琴渐进披露，默认仅展开当前最相关的首条内容。
6. 页面使用间距、标题字重和单一步骤强调线组织信息。普通连续字段不再依赖层层浅色卡片和边框；独立交互、结果、警告和浮层仍可使用容器。
7. 每页的阅读顺序固定为：当前步骤与主要任务；流程位置与设计摘要；理论笔记、参考库和历史。
8. 设计语言持久化在根目录 `DESIGN.md`，后续界面修改应遵循该文件。

## 理由

- 当前任务独占主要画布后，用户不必先筛选左右两列文字，能直接开始操作。
- 摘要与理论属于支持信息，按需出现比永久占宽更符合其使用频率。
- 覆盖抽屉在不改变中央布局的情况下提供完整章节阅读，也避免开合造成内容跳动。
- 固定的三层阅读顺序让长期与一次性两条流程保持一致，降低重复学习成本。
- 保留本机字体、既有配色和离线 SVG，符合本地优先约束，也避免引入与产品无关的通用模板风格。

## 影响

- 工作台初次打开时左右支持面板均关闭；用户可从顶部图标按钮打开。
- 右侧笔记不再占据网格列；中央表单在任何笔记状态下保持原宽度和滚动位置。
- 一次性行为顶部增加三段紧凑路径导航。
- 只改变前端布局和界面状态，不修改 SQLite 数据、自动保存、实践日志或导出格式。
- 现有 ADR-0018 中“理论笔记侧栏”的固定展示方式由本 ADR 替代；其笔记职责、内容映射和不修改原始笔记的决定继续有效。

## 备选方案

### 保留三列，只降低左右栏颜色

未采用。即使降低对比度，两列长文字仍然持续占据宽度和视野，无法解决中央任务被夹击的问题。

### 只允许同时打开一侧，但仍作为固定列

未采用。虽然比三列更轻，但打开笔记仍会挤压当前表单并改变布局位置。

### 删除摘要与笔记

未采用。摘要有跨步骤定位价值，完整理论笔记也承担学习入口；问题在于展示时机而不是内容本身。
