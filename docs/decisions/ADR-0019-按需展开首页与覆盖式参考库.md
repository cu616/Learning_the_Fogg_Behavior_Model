# ADR-0019：按需展开首页与覆盖式参考库

- 状态：已接受
- 日期：2026-08-22

## 背景

首页筛选、两类项目的新建入口和全部项目卡片同时平铺；步骤内参考库使用普通折叠区，展开后会把画布与候选卡片整体向下推。随着项目和参考条目增加，页面会显得拥挤并产生明显布局跳动。右侧模型笔记虽然已经接入，但当前只展示少数摘录，未充分利用用户提供的完整章节笔记。

第七步的“完成本轮，回到首页”还可能被理解为习惯已经完成，而它实际只表示结束当前一次记录操作。

## 决定

1. 首页筛选由平铺按钮改为单个下拉筛选器，搜索框继续独立保留。
2. 长期习惯设计和一次性行为分区默认只显示标题、数量与展开按钮；用户展开后才显示新建入口和项目卡片。
3. 首页项目卡片使用自适应网格：宽桌面优先每行 4 张，较窄桌面回退 3、2、1 张。
4. 参考库的顶层展开内容使用覆盖式浮层，浮在当前卡片和后续内容上方，不改变下方布局位置；浮层内部仍可滚动和继续展开分类。
5. 七步右栏按步骤绑定完整相关章节：第一步额外展示动机章节，第二、三步对应第二章，第四至第六步对应第三至第五章，第七步对应第六、七章。
6. 一次性行为不强制一页只绑定一章；根据捕获、诊断、P/A/M 和行动状态组合多个完整相关章节。
7. 原始 `docs/福格行为模型-右侧提示笔记.md` 保持不变，前端章节结构是其展示映射。
8. 第七步返回首页按钮改为“结束本次记录，回到首页”，明确它只是导航和本次记录结束，不代表习惯培养完成。

## 理由

- 默认收起非当前内容，可以降低首页视觉密度。
- 覆盖式参考库避免用户查看资料时整个页面发生位移。
- 三至四列卡片更充分利用桌面宽度，同时响应式回退保证可读性。
- 完整章节笔记承担模型入门与延伸阅读提示，不必局限于当前控件的直接用途。
- 明确按钮语义可避免把一次实践与长期习惯形成混为一谈。

## 影响

- 首页分区增加本地 UI 展开状态，不改变数据库。
- 参考库浮层需要明确层级、最大高度和窄屏宽度。
- `app/src/foggNotes.ts` 改为完整章节数据与步骤组合映射。
- 数据保存、备份、导出和实践日志结构不变。

## 未采用方案

### 继续平铺全部筛选和项目

未采用。项目增多后会持续占据首屏，并弱化当前想处理的工作流。

### 展开参考库时继续推动页面

未采用。大量条目会造成明显布局跳动，使用户失去原来的视觉位置。
