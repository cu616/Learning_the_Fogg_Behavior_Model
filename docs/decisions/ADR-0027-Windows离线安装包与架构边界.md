# ADR-0027：Windows 离线安装包与架构边界

- 状态：已接受
- 日期：2026-08-22

## 背景

默认 Tauri Windows 安装包使用 `downloadBootstrapper`：目标电脑缺少 WebView2 时，安装阶段需要联网下载运行时。产品核心流程虽然已经离线，但这种默认安装方式不能保证断网电脑成功安装。当前构建工具链为 `x86_64-pc-windows-msvc`，且没有商业代码签名证书。

## 决定

1. 对外分发的首版安装包为 Windows 10/11 x64 NSIS 安装包。
2. `bundle.windows.webviewInstallMode` 使用 `offlineInstaller`，将微软 WebView2 离线安装程序嵌入安装包，目标电脑安装与运行核心功能均不需要网络。
3. 禁止版本降级安装，降低旧版本覆盖新数据库程序的风险。
4. 安装包与便携 EXE 均不声明数字签名；发布说明必须明确 Windows 可能显示“未知发布者”。获得可信代码签名证书后再新增签名决策。
5. 不声称当前安装包支持 Windows ARM64、32 位 Windows、macOS 或 Linux。后续需要这些平台时分别建立构建和测试流程。

## 理由

离线 WebView2 安装包虽然显著增大体积，但能消除目标电脑安装阶段的网络依赖。限定已实际构建和验证的 x64 平台，比提供未经测试的多架构文件更安全。禁止降级可以避免较旧应用代码访问较新数据库结构。

## 影响

- 安装包预计增加约 127 MB。
- 构建机首次打包需要下载微软官方 WebView2 离线安装程序；完成后的安装包无需联网。
- 未签名安装包可能触发 Windows SmartScreen 警告，用户应通过项目提供的 SHA-256 校验值核对文件完整性。

## 备选方案

### 默认下载引导程序

安装包较小，但目标电脑缺少 WebView2 时必须联网，拒绝。

### 固定 WebView2 Runtime

完全随应用携带但体积更大，且需要维护固定运行时版本；当前离线安装器已能满足 Windows 10/11 x64 场景，暂不采用。

### 同时发布未测试的 x86 / ARM64

可能制造架构兼容和数据库迁移风险，拒绝。
