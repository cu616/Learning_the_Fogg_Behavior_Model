# ADR-0026：终止旧习惯画布复用与渐进披露

- 状态：已接受
- 日期：2026-08-22

## 背景

终止旧习惯的“拆解旧习惯”页面把典型时间、地点、人物、情境和选择理由全部直接展示，给用户造成填写压力；具体行为卡片采用静态网格，不能像长期习惯的行为集群一样移动或调整尺寸；“达到当前目标”只改变项目状态，缺少清晰的后续去向。当前全局表面颜色也过于接近白色，工作区层次不足。

## 决定

1. 改变目标与目标范围保持常显，并根据目标类型提供对应名称和示例；典型情境与选择理由合并进默认收起的可选区。
2. 终止旧习惯的具体行为集群复用长期习惯的中心云朵、指向线、可拖动卡片、可缩放卡片、方向键微调与本地持久化交互。
3. 新增数据库迁移保存旧行为卡片的归一化位置及尺寸，不修改已经发布的旧迁移。
4. 完成当前具体行为时，将该行为标记为已达到目标，并明确返回“拆解旧习惯”的行为集群，以便选择下一个具体行为；不把一次具体行为完成等同于强制结束整个项目或返回首页。
5. 删除面向开发实现的元说明，只保留用户做决定所需的文案。
6. 提高画布、工作面和三类首页项目卡片的色差，以协调的蓝灰、暖砂与灰玫瑰表面建立层次，同时保持正文对比度。

## 理由

渐进披露降低初次进入页面的认知负担；复用同一套空间交互能减少学习成本，并为长短文本提供合适尺寸；完成一个具体行为后回到集群符合“一个概括型旧习惯包含多个具体行为”的工作流。使用语义表面色比继续叠加边框更容易形成稳定的视觉层级。

## 影响

- 数据库版本提升至 7，旧数据自动获得空布局值并使用环形默认位置。
- 拖拽不是唯一操作方式，键盘用户可用方向键移动和缩放。
- 项目整体仍可暂停和继续；单个具体行为可依次完成。

## 备选方案

- 保留静态网格：无法解决长短卡片与空间组织问题，拒绝。
- 完成后直接回首页：会打断继续处理同一概括型旧习惯的连续性，拒绝。
- 默认展开全部可选字段：增加填写压力，拒绝。
