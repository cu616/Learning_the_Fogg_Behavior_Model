# ADR-0007：备份保留策略

- 状态：已接受
- 日期：2026-08-21

## 背景

手动备份已实现（`VACUUM INTO` 生成单文件快照并登记 `backup_record`）。若不限制数量，备份文件会无限增长，占用磁盘且难以管理。

## 决定

- 采用**自动滚动备份**：每次备份后只保留最近 **7 份**完整快照，超出部分同时删除 `backup_record` 记录与对应文件。
- 备份文件统一存放在应用数据目录下的 `backups/` 子目录，文件名含时间戳。

## 理由

- 7 份足以覆盖"回退到几天前"的常见需求。
- 滚动删除避免无限增长，逻辑简单、可预期。

## 影响

- 用户始终可看到最近的 7 个备份，并可逐个恢复。
- 后续如需可配置份数或定时自动备份，另立 ADR。

## 未采用方案

- 不限制数量：磁盘无界增长，放弃。
- 按日历分层保留（日/周/月）：更复杂，首版无必要。
