# ADR-0029：森林背景上的 Fluent 深色材质层

- 状态：已被 ADR-0030 替代
- 日期：2026-08-23
- 替代：ADR-0028 中的 Fluent 浅色表面方案
- 被替代：ADR-0030

## 背景

浅色 Fluent 内容层与卡片在蓝灰森林背景上形成了明显的白色块面，削弱了背景与界面的整体感。部分旧组件还使用不透明白色渐变；仅覆盖 `background-color` 无法消除这些渐变，使个别卡片继续表现为白色。

## 决定

1. 改用 Microsoft WinUI 深色主题的语义令牌：基础内容层使用 `#4C3A3A3A`（约 30% 的深灰），普通卡片使用 `#0DFFFFFF`（约 5% 白色叠层），静止控件使用 `#0FFFFFFF`（约 6% 白色叠层），聚焦输入使用 `#B31E1E1E`。
2. 主文字使用白色，次级文字使用 `#C5FFFFFF`，三级文字使用 `#87FFFFFF`；分隔线使用 `#15FFFFFF`。
3. 森林图片保留为基础氛围；顶栏、状态栏和中央工作区使用半透明深灰层，卡片依靠轻微亮层、单像素边界和阴影形成层级。
4. 表面覆盖必须重置完整的 `background` 属性，避免旧的不透明白色渐变继续显示。
5. 七步与三类行为的语义色继续用于图标、选中状态和主要操作，不把所有内容统一染成无差别灰色。
6. 模态遮罩继续使用 30% 黑色；弹出抽屉使用深色实底或单层 Acrylic，长期工作区不叠加模糊。

## 理由

Fluent 深色令牌与森林下半部的深蓝灰色调更接近，能够让界面融入背景，同时依靠官方文字层级维持可读性。完整覆盖 `background` 可修复仅改变背景色却仍保留白色渐变的问题。

## 影响

- 全局文字、控件和长期表面进入深色主题。
- 成功、警告、选中与步骤色仍保留，但只作为语义强调。
- 不改变工作流、数据结构或本地存储。

## 备选方案

### 继续降低浅色卡片透明度

仍会保留白色调，且容易重新进入逐项试色，拒绝。

### 只将部分卡片改成深灰

会出现深色卡片与深色文字混用，并造成浅色/深色主题漂移，拒绝。
