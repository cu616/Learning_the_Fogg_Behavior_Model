# ADR-0013：导出格式升级与向后兼容

- 状态：已接受
- 日期：2026-08-22

## 背景

ADR-0006 的 `fogg-lab-export-v1` 只覆盖最初 14 张业务表。多黄金行为、个人参考库和一次性行为加入后，全量导出需要表达新的外键层级，同时旧导出仍可能被用户用于恢复。

## 决定

- 当前全量导出格式标记为 `fogg-lab-export-v3`：v2 对应多黄金行为和个人库，v3 增加一次性行为三张表。
- 导入器按实际存在的 `tables` 条目工作，不要求旧文件包含新表，因此继续接受 v1、v2 和 v3 数据。
- 所有实体继续以 UUID 去重并在事务内重映射 INTEGER 外键；一次性任务也按 UUID 去重，其诊断轮次和事件随新任务导入。
- “导出单个习惯项目”只导出该长期项目实际使用的数据快照，不附带个人库或一次性任务；“导出全部”包含两类工作流和个人库。
- 数据库备份的 schema 版本同步升级到 4。

## 理由

- 显式版本让导出内容可验证；容忍缺失的新表可以低风险导入旧文件。
- 单项目导出保持边界清楚，避免无意携带用户的其他一次性任务和个人资料。

## 影响

- ADR-0006 中固定为 v1 和 14 张表的描述成为历史基线；本 ADR 是当前格式决定。
- 将来改变字段语义或冲突策略时仍需新版本与新 ADR。

## 未采用方案

### 拒绝所有旧版本

未采用。旧文件的既有表可以安全映射，强制用户先用旧软件转换没有必要。

### 单项目导出同时附带全部个人库和一次性任务

未采用。它超出项目边界，也可能扩大用户无意分享的数据范围。
