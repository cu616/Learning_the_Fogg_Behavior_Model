# ADR-0018：渐进式信息密度与理论笔记侧栏

- 状态：已接受
- 日期：2026-08-22

## 背景

七步工作流已经覆盖主要方法，但页面中同时出现步骤说明、操作提示、空状态说明、右侧方法提示和当前对象说明，造成相同信息多次出现。参考库与当前输入相距过远，也增加了滚动和上下文切换。右侧栏目前偏向重复操作指导，而用户已经提供了一份经过提炼的 `docs/福格行为模型-右侧提示笔记.md`，希望它承担理论入门作用。

## 决定

1. 每个页面只保留一处主要操作引导；能由布局、图标、按钮或流程顺序表达的信息，不再用浅灰小字重复说明。
2. 与输入直接相关的参考库紧邻输入区，并放在同一视觉卡片中；大量参考内容按身份、类型或来源折叠，默认不一次展开。
3. 左侧摘要只展示已经形成的设计结果，不展示“以后再设计”等流程预告；短结果采用两列紧凑摘要。
4. 右侧栏改名为“福格模型笔记”，内容从用户提供的提炼笔记交叉映射到当前七步或一次性行为页面。笔记用于展示理论，不重复当前控件的逐步操作说明，不扩写成替代原书的教程。
5. 一次性行为工作台增加理论笔记侧栏，并随捕获、诊断、P/A/M 调整和行动页面切换内容。
6. 字段标题优先使用小型离线符号图标和较强字重建立识别点；不引入在线图标依赖。
7. 第七步把可选感受和情境合并进折叠区；完成七步后，底部主要动作改为“完成本轮，回到首页”。

## 理由

- 减少重复文字能降低阅读负担，让用户更快识别当前唯一任务。
- 输入与参考资料相邻，更符合“需要时展开”的渐进披露原则。
- 理论笔记和操作指导职责分离后，右栏提供额外学习价值，而不是复述中央页面。
- 一次性行为同样建立在 B=MAP 与 P→A→M 上，应能看到相关理论背景。

## 影响

- 首页新建长期设计入口移入“长期习惯设计”标题行，和一次性行为入口保持一致。
- 第二至第六步的参考区、字段标签和卡片结构发生视觉调整，但不改变数据结构与保存逻辑。
- 工作台右侧数据由独立的前端笔记映射模块提供；原始笔记文档不修改。
- 窄窗口继续隐藏或覆盖侧栏，核心操作不依赖笔记栏。

## 未采用方案

### 把整份笔记按章节完整放入每一页

未采用。章节与软件步骤不是一一对应，完整重复会增加阅读量并削弱当前页面的相关性。

### 删除所有解释文字

未采用。保留每页一处主要引导和必要的理论笔记，避免界面只剩字段而失去行为设计语境。
