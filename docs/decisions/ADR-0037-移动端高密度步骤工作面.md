# ADR-0037：移动端高密度步骤工作面

- 状态：已接受
- 日期：2026-08-23
- 替代范围：替代 ADR-0036 第 4 条中“导航至少 48dp、长表单与卡片统一单列”的绝对规则
- 补充：ADR-0018、ADR-0019、ADR-0021、ADR-0026、ADR-0036

## 背景

完整工作流移植到竖屏后，单列规则让七步导航、参考库、方法选项和实践结果形成过长页面。用户需要频繁纵向滚动，难以在一个视口内同时理解当前问题与可选动作。长期习惯和终止旧习惯中，多数组件是短标签或按需参考资料，不需要独占整行。

## 决定

1. 长期习惯的七个步骤、状态和笔记入口放在同一顶部行；终止旧习惯的五个阶段采用同样结构。项目名称不再占用移动工作台顶部空间。
2. 顶部步骤属于紧凑位置导航，采用短数字目标；主要提交、删除和表单操作继续保持更大的触控目标。任何紧凑目标都必须保留足够高度、明确选中态和间距，不以极小文字代替状态。
3. 同类短选项优先组成二列或三列：第四步三种简化方向一行三项，第七步六种实践结果两行三列；终止旧习惯的准备方式、观察结果和对策方法遵循同一原则。
4. 书中参考库与个人库只保留紧凑触发器。打开后使用视口级覆盖面板，不推动主内容；面板必须提供明确关闭按钮并避开顶部、底部安全区。
5. 移动端行为云和焦点地图采用正方形工作面；愿望云缩小，为可调整行为卡片留出空间。桌面端尺寸与布局保持不变。
6. “尽量一屏看全”用于减少非必要纵向占用，不意味着隐藏必要解释、截断输入结果或让主要操作难以点击。复杂条件字段仍在选择相应方法后渐进出现。
7. 触屏画布中的行为卡片以整张卡片作为拖动表面，并按手指移动增量保持原抓取点，不把卡片中心瞬间跳到触点。删除、缩放、选定等内部操作保持独立；桌面鼠标仍使用拖动柄，键盘方向键继续作为无障碍替代操作。

## 理由

- 同行位置导航直接减少一整行固定高度，并保持状态、笔记和流程位置的空间关系。
- 短标签采用规则网格比连续长条更容易比较，也符合手机拇指扫描路径。
- 参考资料改为覆盖面板后，展开不会造成下方画布跳动，关闭后能准确回到原工作位置。
- 正方形画布与手机有效宽度一致，能避免固定高画布带来的大段空白。

## 影响

- 移动样式不再全局把 `field-grid`、`method-cards`、`choice-grid` 强制为单列，而是按任务语义分别设置列数。
- 参考库内容使用固定定位层，层级高于工作面，低于系统级错误提示。
- 桌面工作台、数据库和保存格式不变。

## 备选方案

### 所有控件继续单列

触控目标宽大，但页面过长且同类选项难以比较，不采用。

### 缩小所有文字和控件以强行塞入一屏

会降低阅读和触控可靠性，也无法处理条件字段动态出现的情况，不采用。

### 为每个选项再增加独立子页面

纵向长度会减少，但步骤层级与返回成本显著增加，不适合频繁试选，不采用。
