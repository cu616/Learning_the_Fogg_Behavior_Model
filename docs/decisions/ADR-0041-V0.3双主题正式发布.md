# ADR-0041：V0.3 双主题正式发布

- 状态：已接受
- 日期：2026-08-25
- 补充：ADR-0038、ADR-0040

## 背景

V0.2 已形成 Windows 与 Android 共用的三类行为工作流。随后主分支通过真实 Git 合并吸收协作者的孤独摇滚视觉分支，并按 ADR-0040 将其重构为与专业模式并存的可选主题。用户需要一组可直接测试的 Windows 便携版、离线安装包和 Android APK。

## 决定

1. 应用版本统一升级为 `0.3.0`，Git 标签和 GitHub Release 使用 `v0.3.0`。
2. V0.3 同时发布三个文件：Windows x64 便携 EXE、带 WebView2 的 Windows x64 离线 NSIS 安装包、Android 7.0+ ARM64 APK。
3. 专业模式继续作为首次启动默认主题；孤独摇滚模式由用户在“数据与外观”中主动切换。
4. 两种主题共享同一数据结构和三类行为工作流，V0.3 不新增数据库迁移，也不改变导入导出格式。
5. Android APK 继续使用调试签名，仅用于侧载测试；Windows 文件仍未购买商业代码签名证书。每个发行文件必须公布 SHA-256。
6. Android 运行时继续不声明 `INTERNET` 权限。主题资源随安装文件离线提供，主题切换不访问网络。
7. 孤独摇滚角色素材的来源记录不等于再分发授权。此次发布面向仓库所有者与受控测试；若扩大公开或商业分发范围，必须先确认授权或替换素材。

## 理由

- 同一版本号和同一 Release 能让桌面与手机测试反馈对应到完全相同的产品状态。
- 保持 schema 和导出格式不变可降低从 V0.2 升级测试的风险。
- 继续使用现有离线安装与侧载边界，避免把主题合并扩大成签名或商店发行项目。

## 影响

- package、Cargo、Tauri 与 Android 版本信息同步为 `0.3.0`，Android `versionCode` 为 `3000`。
- 新增 V0.3 发布说明、校验值和三个 GitHub Release 附件。
- 仓库仍不提交 EXE、Setup 或 APK 二进制；它们只保存在本地发行目录并作为 Release 附件上传。

## 备选方案

### 继续沿用 V0.2 版本号

会让双主题版本与既有 V0.2 二进制无法区分，不采用。

### 只提供一个平台进行测试

无法确认共享代码在 Windows 与 Android 上的主题兼容性，也不符合当前双平台维护方式，不采用。
