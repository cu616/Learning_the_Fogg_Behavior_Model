# ADR-0037：跟做式说明与行为设计排练册

- 状态：已接受
- 日期：2026-08-23
- 调整：[ADR-0018](./ADR-0018-渐进式信息密度与理论笔记侧栏.md)、[ADR-0022](./ADR-0022-常驻设计状态栏与湖绿工作面.md)
- 扩展：[ADR-0034](./ADR-0034-离线用户说明与方法学习路径.md)、[ADR-0036](./ADR-0036-青春乐队漫画主题替代交响诗篇主题.md)
- 后续调整：[ADR-0038](./ADR-0038-界面不展示原书页码与情境化说明重构.md) 取消界面页码尾注，并重构说明书案例与卡点处理方式。

## 背景

原“福格模型笔记”只是理论标题和摘要的折叠列表，用户看完仍不知道应该观察什么、问自己什么、下一步改什么。软件内使用说明虽然覆盖三类工作流，但更像产品介绍，缺少可跟做的完整案例、完成判断和可照抄句式。手机端继续缩放桌面自由画布还会造成候选行为重叠。

## 决定

1. 将“福格模型笔记”重新定位并命名为“行为设计排练册”。它仍是按需打开的覆盖抽屉，不成为主流程中的强制步骤。
2. 排练册固定按“当前结论—看现实信号—问一个问题—只改一件事”组织；每个条目同时提供要点、一个自问问题、现在可以做的动作和原书 PDF 物理页码。
3. 原书页码只承担回查证据的作用，不使用微型章节眉题或冗长书目元数据。此前“不显示来源小字”的决定被本条调整。
4. 软件内说明改为可跟做教程：先解释 `B = MAP`，再区分三类工作流，用“让白天更有精神”走完七步，并补充一次性行为演练、现实诊断表、终止旧习惯、可照抄模板和常见问题。
5. 每个长期习惯步骤同时说明“本步问题、现在做什么、示例结果、可以继续的判断”，帮助没有读过原书的用户理解完成标准。
6. 动漫角色台词只负责建立排练语境和降低陌生感；方法判断仍由现实证据、用户选择和福格模型承担。
7. 桌面端第二步保留自由拖拽行为画布；不适合精细拖拽的手机端改为“愿望卡 + 纵向候选行为清单”，不显示无效的拖拽与缩放控件。
8. 本变更不引入网络、AI 或个人数据外传，也不改变 SQLite 数据结构和三类工作流。

## 理由

- 零基础用户需要从概念直接过渡到判断和动作，而不是继续阅读另一份摘要。
- 单一连续案例能让愿望、行为、黄金行为、微小化、锚点、庆祝和诊断形成因果链。
- 页码使产品化解释可回查，避免把软件提示误认为脱离原书的权威结论。
- 手机端用列表承载候选行为比把空间画布强行压缩到 390px 更清楚、更可操作。

## 影响

- `FoggNotePanel.tsx` 与 `foggNotes.ts` 改为完整方法卡结构，并在三类工作台统一使用“行为设计排练册”名称。
- `UserGuide.tsx` 变为八章跟做式说明，保持完全离线。
- `kessokuTheme.css` 增加排练册、说明书和手机端行为清单的独立响应式规则。
- 浏览器演示数据覆盖长期习惯主要读取链路，可用于本地交互和视觉回归。

## 备选方案

### 继续增加理论摘要数量

信息更多但仍缺少判断和动作，拒绝。

### 把完整说明做成首次启动强制教程

会增加开始行为设计的门槛，也不适合已有经验的用户，拒绝。

### 手机端继续使用缩小后的自由画布

卡片重叠、拖拽精度差，不能算真正适配，拒绝。
