# ADR-0028：离线风景背景与分层磨砂工作面

- 状态：已被 ADR-0029 替代
- 日期：2026-08-23

## 背景

现有界面通过纯色冷灰蓝画布和非纯白卡片建立层次，清晰但氛围仍偏平。用户希望参考浏览器新标签页的视觉语言：统一色调的风景背景经过暗化，上方承载略透明的卡片和工作面，让软件更像愿意长期停留的个人空间。

## 决定

1. 使用项目自有、随应用离线提供的低细节蓝灰山林风景图作为全局底层背景，不引用在线图片或运行时网络资源。
2. 背景图固定铺满窗口，并使用同一 50% Fluent 内容层作为浅色 Mica 式基底，降低局部明暗变化与视觉噪声；不叠加黑色遮罩。
3. 透明层级采用 Microsoft Fluent/WinUI 浅色主题的官方语义令牌：大面积内容层使用 50% 白色（`LayerFillColorDefault`），普通卡片和静止控件使用 70% 白色（`CardBackgroundFillColorDefault` / `ControlFillColorDefault`），聚焦输入使用纯白，模态遮罩使用 30% 黑色（`SmokeFillColorDefault`）。
4. 长期存在的顶栏、状态栏与中央工作区不使用 Acrylic 模糊；只有参考抽屉、弹出库和模态浮层使用一次模糊。避免相邻或嵌套多层 Acrylic。
5. 七步协调色谱继续用于流程定位、图标、选择状态和主要动作，不用风景图替代语义色。
6. 正文所在表面必须保证稳定背景和可读对比度；背景不得动画、滚动或参与任务状态表达。

## 理由

风景图能增加安静、陪伴和空间感；分层磨砂比高透明玻璃更适合本产品的大量文字与表单。将图片随应用内置可保持本地优先和离线可用。背景不再额外叠加长期黑色遮罩；若大工作面接近不透明且高强度模糊，会退化成“暗底上的白纸”，失去采用风景背景的意义。使用 Fluent 官方层级令牌可避免继续凭观感逐项调整透明度。

官方依据：

- Microsoft Mica material：Mica 作为基础层，内容层使用低透明度 `LayerFillColorDefaultBrush`。
- Microsoft Acrylic material：Acrylic 主要用于临时浮层，不应用于大型长期背景，也不应并排叠放多层。
- Microsoft WinUI `Common_themeresources_any.xaml`：浅色主题的内容层、卡片、控件、描边、文字和 Smoke 的实际颜色令牌。

## 影响

- 前端增加一张本地背景图片资源，生产构建体积略有增加。
- 首页、长期习惯、一次性行为和终止旧习惯共享同一氛围骨架，但保留各自流程强调色。
- 不改变任何用户数据、工作流或数据库结构。

## 备选方案

### 所有卡片高度透明

视觉效果更强，但长文本和表单的对比度会随背景区域变化，拒绝。

### 只使用 CSS 渐变

性能稳定但无法提供用户希望的自然风景氛围，保留为未来简洁模式的备选。

### 在线随机背景

破坏离线和隐私边界，也造成不可预测的对比度，拒绝。
