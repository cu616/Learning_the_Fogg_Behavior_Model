- Edge 扩展 ID：`bpelnogcookhocnaokfpoeinibimbeff`。
- 商店版本：`2.2.42`。
- CRX 格式：CRX3；Manifest V3。

## 页面基础设置

- 主页面默认正文：`14px`，行高约 `1.414`。
- 字体栈优先顺序：Apple 系统字体、Helvetica Neue、苹方、微软雅黑、思源黑体、Noto Sans CJK SC、文泉驿微米黑，最后回退到无衬线字体。
- 主页面根据系统深浅模式切换主题；深色页面加载前的后备背景为 `#38383D`。
- 主要字号集中在 `12 / 13 / 14 / 16 / 18 / 20 / 24 / 28 / 38 / 40px`。
- 主要字重为 `400 / 500 / 600 / 700`，其中正文以 400 为主，标题和重要操作使用 500–700。

## 核心材质配方

### 搜索框

- 尺寸：默认宽约 `568px`，可配置范围由 `520px + 340px × 设置比例` 得到；最大宽度 `86vw`。
- 位置：顶部约 `12vh`。
- 高度：`52px`。
- 圆角：`12px`。
- 边框：1px 白色；静止约 10%，展开约 20%。
- 浅色主题背景：白色 60%；聚焦或展开时白色 80%。
- 深色主题聚焦/展开背景：黑色 70%。
- 输入文字：`16px`；占位文字为主文字的 40%。
- 状态过渡：约 `100ms`，只改变颜色和透明度。

### 普通 Glass Card

- 背景：浅色主题白色 80%；深色主题黑色 70%。
- 边框：浅色主题白色 40%；深色主题白色 10%。
- 模糊：`40px`。
- 圆角：`12px`。
- 阴影：`0 2px 12px rgba(0,0,0,0.15)`。

### Dock

- 背景：浅色主题白色 40%；深色主题黑色 30%。
- 边框：浅色主题白色 20%；深色主题白色 16%。
- 模糊：`20px`。
- 圆角：`24px`，运行时也会依据 Dock 高度计算约 28% 的圆角。
- 阴影：`0 0 12px rgba(0,0,0,0.25)`。

### 左侧栏

- 背景：黑色 40%。
- 模糊：`40px`。
- 饱和度：`200%`。
- 圆角：`16px`；全高展开模式取消圆角。
- 常规窄栏宽度：`52px`。

### 菜单、弹窗和悬浮面

- 菜单阴影：`0 0 1px rgba(0,0,0,0.08), 0 4px 8px -4px rgba(0,0,0,0.08)`。
- 普通小组件阴影：`0 4px 12px rgba(0,0,0,0.05)`。
- 侧栏/菜单卡片阴影：`0 2px 12px rgba(0,0,0,0.15)`。
- 对话框阴影：`0 16px 24px -14px rgba(0,0,0,0.23)`。
- 小组件预览的双层阴影：两个低透明度、不同垂直距离的投影，用于形成较柔和的悬浮感。
- 高频内描边：1px 白色 5% / 8% / 10% / 12% / 16% / 20%，根据表面高度递增。

## 视觉协调的关键结论

1. WeTab 并非使用一个统一的“毛玻璃透明度”。搜索框、普通卡片、Dock、侧栏和弹窗分别采用不同配方。
2. 深色主题的主要浮卡不是“白色 5% 叠在背景上”，而是接近黑色 70% 的稳定阅读面；只有 Dock 和侧栏保留较强的壁纸穿透。
3. 材质越临时、越靠近用户，边界和阴影越明确；常驻背景层反而更安静。
4. 透明卡片的协调感同时依赖灰阶 Token、透明度、模糊、内描边和投影，不能只调整其中一个参数。
5. 14px 正文、16px 输入/小标题、20px 以上页面标题构成主字号骨架；12–13px 只用于辅助信息。

## 对本项目的适配建议

不应把 WeTab 参数逐项覆盖到所有页面。建议按角色映射：

| 本项目表面 | 建议参考的 WeTab 配方 | 原因 |
|---|---|---|
| 首页顶栏、三类行为总览 | Dock/侧栏配方 | 允许森林背景参与氛围，界面安静 |
| 中央七步工作面 | 深色 Glass Card 的黑色 70% | 承载长文字和表单，需要稳定对比度 |
| 左侧行为状态栏 | 侧栏 40% 黑色作为起点，但降低或取消持续模糊 | 保留定位感，避免长期争夺视觉焦点和 GPU |
| 输入框 | 搜索框的 60% 静止、70%–80% 聚焦阶梯 | 用材质变化表达交互状态 |
| 参考库、抽屉、菜单 | 普通 Glass Card / 菜单阴影 | 属于临时悬浮面，适合明显抬升 |
| 内部普通信息卡 | 不重复使用 40px 模糊，只用半透明色、1px 内描边和低阴影 | 避免多层 Acrylic 叠加和灰雾感 |

## 与当前主题的主要差距

- 当前普通卡片使用约 5% 白色叠层；WeTab 深色普通浮卡使用约 70% 黑色，阅读面明显更稳定。
- 当前主要工作面使用约 30% 深灰层；WeTab 的常驻穿透面与内容浮卡之间反差更大。
- 当前模糊使用较克制；WeTab 对 Dock、侧栏和浮卡分别使用 20px、40px 以及 200% 饱和，但不能直接在嵌套表单中全部启用。
- 当前字号体系接近 WeTab，但需要进一步统一 12/14/16/20/24 的语义角色，减少零散字号。

## 后续实现边界

- 只复用上述抽象参数和分层方法，不复制原扩展的源代码或资源。
- 首先做首页和一个长期习惯步骤页的 A/B 原型，再决定是否推广到所有流程。
- 为 `prefers-reduced-transparency`、低性能环境和背景图片加载失败保留实色深灰回退。
- 所有正文仍需针对实际合成后的背景验证至少 4.5:1 对比度。
