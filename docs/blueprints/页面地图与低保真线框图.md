## 1. 页面地图

```text
应用
├─ 首页（仪表盘）
│   ├─ 今日实践（今日锚点提醒 + 快速记录）
│   ├─ 我的行为设计（项目列表：筛选/搜索/分组/归档）
│   └─ [新建设计]
├─ 七步工作台（每个习惯项目一个，1–7 步）
│   ├─ 第 1 步 明确愿望
│   ├─ 第 2 步 探索行为选项（行为集群）
│   ├─ 第 3 步 匹配黄金行为（焦点地图）
│   ├─ 第 4 步 从微习惯开始（能力链 + 容易做分析）
│   ├─ 第 5 步 找到「对」的提示（锚点匹配）
│   ├─ 第 6 步 庆祝成功（庆祝实验 + 配方卡）
│   └─ 第 7 步 排除障碍、重复与扩展（今日记录/诊断/扩展）
├─ 参考库浏览（只读，嵌入各步辅助栏或独立弹窗）
└─ 本地数据管理（备份 / 导出 / 恢复 / 隐私）
```

## 2. 七步工作台统一框架

```text
┌────────────────────────────────────────────────────────────────┐
│ ← 返回首页   习惯名：早起阅读     进度 ●●○○○○○   [已保存 ✓]  [配方草稿] │
├──────────────────────────────────────┬─────────────────────────┤
│                                      │ 辅助栏（默认折叠）       │
│ 中央主工作区                          │  · 这一步为什么重要      │
│  [当前步骤目标]                       │  · 概念解释              │
│  [逐题引导 / 可操作工具]              │  · 判断标准 / 正反例     │
│  [本步结果预览]                       │  · 常见误区              │
│                                      │  · PDF 页码              │
│                                      │  · [展开知识库原文]       │
├──────────────────────────────────────┴─────────────────────────┤
│ [← 上一步]  [保存草稿]  [稍后决定]  [查看影响]  [完成并继续 →]    │
└────────────────────────────────────────────────────────────────┘
```

统一映射：顶部进度对应 `habit_project.current_step`；「已保存」对应字段级自动保存状态；「配方草稿」读取最新 `recipe_version`（或尚未生成时显示第 6 步草稿）。

## 3. 各屏线框

### 3.1 首页（仪表盘）

```text
┌───────────────────────────────────────────────┐
│ 福格行为实验室                    [新建设计]     │
├───────────────────────────────────────────────┤
│ 今日实践                                      │
│  ☐ 早起阅读  在我[喝完第一口水]之后 → 读一页    [完成][多做][没做][忘了] │
│  ☐ 睡前拉伸  在我[刷完牙]之后 → 拉伸一次       [完成][多做][没做][忘了] │
├───────────────────────────────────────────────┤
│ 我的行为设计     筛选:[设计中][实践中][稳定][暂停][归档]  搜索:[___] │
│  按愿望领域分组                                │
│  ▸ 健康                                      │
│     · 早起阅读         实践中    下一步: 处理「没做」诊断 │
│     · 喝水             稳定      复制           │
│  ▸ 专注                                      │
│     · 番茄工作         设计中    继续第 3 步     │
└───────────────────────────────────────────────┘
```

对应：项目列表 = `habit_project`（`phase`/`paused_at`/`archived_at` 驱动筛选）；「下一步行动」来自 `current_step` 或未处理的 `obstacle_diagnosis`。

### 3.4 第 3 步 匹配黄金行为（焦点地图）

### 3.5 第 4 步 从微习惯开始（能力链）

```text
┌ 第 4 步 · 从微习惯开始 ──────────────────────────┐
│ 原行为：每天跑步 30 分钟                          │
│ 能力链：时间○ 资金○ 体力● 脑力○ 日程○   （●最弱）  │
│ 简化方式：[x]缩小规模  [ ]入门步骤  [ ]工具资源  [ ]提升技能 │
│ 微行为：步行 2 分钟        入门步骤：穿上跑鞋      │
│ 基线行为：穿上跑鞋并走到门外                       │
│ 可选扩展：如果愿意，可以继续步行                    │

│ [确认基线]                                       │
└───────────────────────────────────────────────┘
```

对应：`ability_assessment`（五因素 + weakest_link + simplification_methods）+ `tiny_behavior`（original_behavior / tiny_behavior / entry_step / baseline / optional_extension）。

### 3.8 第 7 步 排除障碍、重复与扩展

```text
┌ 第 7 步 · 实践与迭代 ────────────────────────────┐
│ 今日：   自然完成了 · 多做了 · 想起没做 · 忘了 · 没锚点 · 不方便 │
│ 若成功 → 先复现庆祝：「双手比赞！」  [感受成功]     │
│ 若未完成 → 诊断（提示→能力→动机）                  │
│   Q: 完全忘记 → 锚点不可靠 → 建议返回第 5 步        │
│      [返回第 5 步]  [稍后处理]                     │
│ 配方版本：v1（active）  [历史]                     │
│ 累计成功 12 · 最近稳定 · [暂停][恢复][归档]        │
│ 扩展建议：你最近常多做，是否扩大？ [稍后再看]       │
└───────────────────────────────────────────────┘
```

对应：`practice_event`（result / feeling / context / recipe_version_id）+ `obstacle_diagnosis`（obstacle_type / diagnosis_path / return_step / user_decision）+ `recipe_version`（status）。
