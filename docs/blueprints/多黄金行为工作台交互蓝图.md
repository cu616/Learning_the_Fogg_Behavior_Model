# 多黄金行为工作台交互蓝图

> 本文落实 ADR-0010，描述下一轮七步工作台重构的目标交互。它补充现有页面地图和七步 PRD；发生冲突时，以已接受 ADR 为准。

## 一、工作台总体结构

```text
┌──────────────┬──────────────────────────────┬──────────────────┐
│ 设计摘要      │ 当前步骤                     │ 方法提示          │
│              │                              │                  │
│ 最终愿望      │ 当前操作区                   │ 书中关键问题      │
│ 黄金行为 A    │                              │ 常见误区          │
│  ├ 微习惯 A1  │                              │ PDF 回查页码      │
│  └ 微习惯 A2  │                              │                  │
│ 黄金行为 B    │                              │                  │
│              │                              │                  │
│ 当前基线      │                              │                  │
│ 可选扩展      │                              │                  │
└──────────────┴──────────────────────────────┴──────────────────┘
```

- 左栏回答“我已经决定了什么”。
- 中栏回答“我现在需要做什么”。
- 右栏回答“书中的方法是什么、要避免什么”。
- 左栏内容只随已完成决定逐渐出现，不展示大批空值。
- 用户切换左栏分支后，中栏步骤仍保持不变，但编辑对象切换到所选分支。

## 二、信息层级

### 愿望项目

保存最终愿望、原因、生活变化及项目整体状态。

### 黄金行为

来自第三步焦点地图。一个愿望项目可以选中多个黄金行为。

### 微习惯分支

隶属于一项黄金行为，是步骤四至步骤七的独立操作单位。每个分支拥有自己的：

- 能力链判断；
- 简化策略和微行为；
- 基线行为与可选扩展；
- 锚点；
- 庆祝方式；
- 配方版本；
- 实践感受和诊断记录；
- 生命周期状态。

默认情况下，用户选择黄金行为后可以创建第一个微习惯分支；只有用户主动添加时才出现更多分支，避免一开始制造复杂度。

## 三、第一步：低负担地确认愿望

```text
最终愿望
┌────────────────────────────────────────┐
│ 我希望……                               │
└────────────────────────────────────────┘

▸ 帮助我想一想（非必填）
```

展开可选区域后显示两条提示：

- 这对你为什么重要？
- 如果改变，生活会有什么不同？

两条提示共用一个思考记录框。此处不填写也能继续；其作用是帮助用户改写上方的最终愿望，不是收集完整问卷。

## 四、第二步：行为集群画布

```text
       [候选行为] ──────┐
                        ↓
[候选行为] ─────→  ☁ 最终愿望 ☁  ←───── [候选行为]
                        ↑
       [候选行为] ──────┘
```

- 中央云朵直接读取第一步的最终愿望。
- 新增行为后生成一张小纸条式卡片，箭头从卡片指向云朵。
- 卡片可原地编辑、拖动、暂存和删除。
- 初始卡片由布局算法分布在云朵四周；用户可以重新排列。
- 行为超过当前空间时扩展画布，并提供缩放、平移和“整理布局”。
- 本步骤始终只发散，不显示评分或候选区。
- 保留列表替代视图，确保键盘操作和窄窗口可用。

## 五、第三步：焦点地图

### 地图

- 纵轴：影响低 → 影响高。
- 横轴：难以做到 → 容易做到。
- 横纵轴各有九级刻度，右上角用柔和颜色标出黄金行为候选区域。
- 候选行为以卡片形式放置；卡片可连续拖动，不强制吸附到离散格点。
- 拖动第一轮重点提示“先只判断影响”；进入第二轮后提示“再横向判断现实可行性”。

### 选择

- 进入右上区域只代表“候选”，不会自动变成已选黄金行为。
- 卡片提供“选为黄金行为”开关，允许选择多张。
- 左侧摘要立即列出已经确认的黄金行为。
- 重叠卡片应轻微错位或形成可展开堆叠，不能完全遮住。
- 键盘用户可按九级影响/可行性选择器移动卡片。

## 六、第四步：能力链和简化

### 能力链

```text
[时间]—[资金]—[体力]—[脑力]—[日程]
                    ↑
                 最薄弱环节
```

- 每个环节是一段可点击的链节。
- 选中后突出显示，并询问：“具体是什么让这个行为难以做到？”
- 默认只要求选出最薄弱环节，不要求给所有环节评分。

### 简化方式

```text
怎样让它更容易？

[提升技能]  [工具和资源]  [让行为变得微小]
                               ├─ 入门步骤
                               └─ 缩小规模
```

- 可选择一种或多种方式。
- 只展开已选方式对应的输入卡片。
- 入门步骤和缩小规模共享“原行为”，但各自显示不同的结果字段。
- “基线行为”和“可选扩展”固定显示在简化区底部。
- 原行为到微行为采用左右对照布局：

```text
┌──────────────┐      →      ┌──────────────┐
│ 原行为        │             │ 简化后的微行为 │
└──────────────┘             └──────────────┘
```

## 七、第二步参考库的职责

附录配方浏览器保留，但更名为“从书中配方获得行为灵感”。点击某条完整配方后，不立即写入候选行为，而是打开确认卡：

```text
书中完整示例：在我刷完牙之后，我会用牙线清洁一颗牙齿。

这条示例里的候选行为是：
[ 用牙线清洁牙齿                         ]

[加入候选行为]  [取消]
```

- 锚点文本只作为示例来源保留，不成为正式锚点。
- 第五步可再次展示来源配方供参考，但必须由用户确认锚点是否适合自己的地点、频率、主题和最后动作。

## 八、第七步实践记录

记录区分两层：

1. 快速选择本次结果；
2. 可选填写本次感受。

```text
本次结果
[自然完成] [完成且多做] [想起但没做] [完全忘记] [...]

这次有什么感受或发现？（可选）
┌────────────────────────────────────────┐
│ 当时很累，但只做一个动作完全没有压力…… │
└────────────────────────────────────────┘

[保存这次实践]
```

- 结果和感受应一次提交，避免先生成缺少感受的记录。
- 成功结果保存后立即展示所选庆祝方式。
- 非成功结果保存后再运行相应诊断。
- 历史记录显示结果、时间和一行感受摘要，点击后查看全文。

## 九、建议实施顺序

1. 先加入第七步感受输入和历史展示；现有数据库已支持。
2. 简化第一步，只保留最终愿望主输入和可折叠思考区。
3. 修正第二步参考库，停止直接写入完整配方。
4. 实现第二步行为集群画布。
5. 完成多黄金行为/微习惯分支的数据迁移及导入导出兼容。
6. 重构左侧渐进式摘要和分支切换。
7. 实现九级连续焦点地图。
8. 实现第四步能力链与条件字段。
9. 联调步骤五至七的分支级配方、实践和诊断。

## 十、尚待继续讨论

- 一个黄金行为首次进入第四步时，是自动创建一个微习惯分支，还是先要求用户命名。
- 多个微习惯分支是否允许同时进入实践，还是默认一次只激活一个。
- 焦点地图右上候选区对应九级坐标的具体阈值。
