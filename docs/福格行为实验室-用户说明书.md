# 福格行为实验室·用户说明书

> 适合没有读过《福格行为模型》的用户。你不需要先掌握理论；只要愿意把行为当成一个可以小步试验、根据现实修改的设计。

## 1. 先记住三条心法

### 心法一：不要先问“我为什么没自律”

当一个行为没有发生，先问三件事：

1. 当时有没有清楚的提示？
2. 这个行为当时是不是足够容易？
3. 最后才问：我当时是不是真的想做？

福格模型把这三个条件称为 Motivation、Ability 和 Prompt。它们需要在同一个具体时刻相遇：有一点想做，做起来足够容易，而且恰好出现了开始信号。软件通常先检查提示和难度，因为这两处更容易从现实中看见并调整；两者都合适时，再回头判断动机。

### 心法二：让行为小到不需要等动力

动机会波动，很难长期保持在高位。更稳定的做法是降低行为难度。例如：

- 不先要求“跑步 30 分钟”，可以从“穿上跑鞋”开始；
- 不先要求“读完一章”，可以从“读一段”开始；
- 不先要求“整理整间房”，可以从“收好一件物品”开始。

基线是你状态不好时仍然能做的部分。多做是可选扩展，不要把它偷偷升级成新的最低标准。

### 心法三：用成功感帮助大脑学习

做完微小行为后，立即用一个真实、自然的动作让自己感到“我做到了”。这是庆祝，不是等几天后再领取的奖励。

你可以微笑、轻点一下头、在心里说“不错”，或者做一个很小的胜利动作。如果感到尴尬、假或者像在表演，就换一种；庆祝应当适合你，不是取悦软件。

## 2. 先选对工作流

| 你想处理的事 | 选择 | 例子 |
|---|---|---|
| 希望一个新行为以后继续发生 | 长期习惯设计 | 午饭后走到楼梯口、晚饭后读一页书 |
| 完成一次就结束 | 一次性行为 | 预约年度体检、补办证件、确认一次行程 |
| 它已经在重复，希望让它减少、停止或被替代 | 终止旧习惯 | 躺到床上后打开短视频、半夜醒来查看消息 |

判断不准也没关系。一次性行为如果后来发现需要重复，可以再转为长期习惯设计。

## 3. 十分钟快速开始

1. 在首页展开对应类别，输入一句话创建实验。
2. 只完成当前页中最突出的一个任务，可选解释和参考库可以以后再看。
3. 第一版不追求完美；只要它小到愿意去现实中试一次。
4. 现实中发生或没有发生后，回来做一次快速记录。
5. 如果卡住，从最像真实原因的地方开始尝试，再看下一次发生了什么。

### 如何使用软件里的“行为设计排练册”

每个工作台右上角都可以打开排练册。它不是另一套必须读完的课程，正确用法只有四步：

1. 先读顶部的“当前结论”，确认这一页最重要的判断。
2. 展开第一条方法卡，只回答“问自己”里的一个问题。
3. 照着“现在可以做”完成一个动作，然后关闭排练册回到工作区。
4. 得到当前动作后就关闭排练册，回到工作区；不需要为了继续操作先读完其他卡片。

排练册会帮助你从最可能的原因开始。现实结果不是成绩单，而是下一次设计的证据。

## 4. 长期习惯：跟着七步做一遍

下面用一个有真实限制的情境作为连续例子：小林在办公室工作，下午经常久坐，但没有稳定时间去健身。她想让工作日的身体多活动一点，又不想再订一个靠意志力硬撑的计划。

### 第一步：明确愿望

问：我真正想改变的方向是什么？

- 愿望可以先写方向：“让工作日的身体多活动一点”。
- 愿望不必在此时就写成任务或承诺。
- 这一步够好的标志：你愿意继续为这个方向探索。

常见误区：一上来就写“每天跑 30 分钟”。这已经是一个具体行为，它是否适合你还没有被验证。

### 第二步：探索行为选项

问：有哪些具体行为可能帮助这个愿望？

先发散，不筛选。可能包括：早上拉伸、午饭后走到楼梯口、下午接水、晚饭后散步。

行为应该是可以被看见的动作。“更健康”不是行为，“接一杯水”是。

### 第三步：匹配黄金行为

把候选行为放到焦点地图上，同时问：

- 它对愿望的影响大吗？
- 以我现在的环境，它做得到吗？
- 我真的想做吗？

例子中，“把午餐餐具放回去后，走到楼梯口”同时符合办公楼环境、意愿和可行性，因而成为黄金行为。别人认为有效的行为，不一定是你的黄金行为。

### 第四步：从微习惯开始

检查能力链：时间、资金、体力、脑力、日程。整条链的强度取决于最薄弱的一环。

假设午饭后时间很少，可以把基线缩小为“走到楼梯口”，可选扩展是“如果愿意，再多走一层”。

用最低动机测试：在疲惫、忙碌或心情一般的那天，你仍然相信自己做得到吗？如果不确定，再变小。

### 第五步：找到“对的”提示

不要只写“中午”或“有空时”。选择一个已经稳定发生的锚点，并精确到它的最后动作。

例如：“在我把午餐餐具放回回收处之后，我会走到楼梯口。”

好锚点需要同时匹配地点、频率和情境，而且锚点结束后能立即开始新行为。

### 第六步：庆祝成功

选一个自然的即时庆祝，例如轻轻握拳并在心里说“这一拍接上了”。完整配方变成：

> 在我把午餐餐具放回回收处之后，我会走到楼梯口，然后轻轻握拳并在心里说“这一拍接上了”。

当场在想象中或真实场景里演练几次“锚点 → 微行为 → 庆祝”，比只把配方写下来更有帮助。

### 第七步：排除障碍、重复和扩展

现实中试验后，用几秒记录发生了什么。如果没有发生：

- 完全忘记：先回第五步检查锚点。
- 想起来但没做：先回第四步检查是否足够容易。
- 长期不想做：回第三步检查是否选对了行为。
- 庆祝很别扭：回第六步换一种。

每次只修改一个主要因素。不需要因为中断把之前的成功清零，也不需要在状态不好时强迫自己完成扩展行为。

## 5. 一次性行为：越过这一次行动线

例子：“预约一次年度体检”。这件事没有固定时间，医院和检查项目也还没有完全确定，因此一直停在待办清单里。

1. 写清完成标准：“收到医院确认，预约日期已经进入日历”。
2. 把下一动作改成：“找到常用医院的预约入口”。此时不用先规划完整体检流程。
3. 如果现在没有做，先检查提示：有没有一个真实、清楚的开始时刻？
4. 再检查能力：是不知道挂哪个科、医保卡不在手边，还是开放日期不合适？
5. 能做就现在打开；需要资料就安排到拿到资料之后；仍不确定就保存这一轮诊断，而不是继续扩大计划。

软件中的时间和地点只是你保存在本机的提示方案，当前不会自动创建系统闹钟或通知。

## 6. 终止旧习惯：改设计，不和自己硬碰硬

例子：“减少睡前长时间刷手机”。

### 先拆成具体行为

“玩手机太多”可能包含很多不同行为：躺下后打开短视频、半夜醒来查看消息、关灯后继续刷新动态。一次聚焦一个最容易改变的具体行为。

### 对终止行为，先处理提示，再处理难度

1. 提示：能否移除、规避或忽略提示？例如把手机放到卧室外充电。
2. 能力：能否让旧行为更难做？例如退出账号、移除桌面入口、增加几个打开步骤。
3. 动机：最后才调整刺激因素或重新评估改变理由。
4. 替代：如果需要，把原来的提示接到一个更容易、更有吸引力的新行为上。

旧行为再次发生时，记录当时的提示、未覆盖情境和对策缺口。这是新证据，不是一次道德判决。

> 严重成瘾、进食障碍、自伤或可能伤害他人的情况，不应只依赖本软件，请寻求合格的医疗、心理或其他专业支持。

## 7. 一张可以反复使用的诊断表

| 现实发生了什么 | 先检查 | 常见调整 |
|---|---|---|
| 完全忘记 | 提示 | 换更稳定的锚点，精确到最后动作 |
| 锚点没有出现 | 提示 | 换一个频率和日程更匹配的锚点 |
| 想起来但没做 | 能力 | 找到最薄弱环节，使用入门步骤或缩小规模 |
| 经常不想做 | 动机 / 行为匹配 | 换一个自己更愿意的黄金行为 |
| 做了，但庆祝很别扭 | 庆祝 | 换成更安静、更真实的成功感 |
| 环境已经改变 | 能力和提示 | 先更新配方，不要用旧环境的标准要求现在的自己 |

## 8. 什么时候才扩展

只有在你经常自然多做、能力已经提高，或者主动想增长时，才考虑扩展。你可以：

- 保持原基线不变；
- 稍微增加数量、时长或难度；
- 在同一愿望下另选一个黄金行为；
- 为同一黄金行为新建另一个微习惯方案。

原来的微行为可以永远作为状态不好时的最低基线。

## 9. 卡住时怎么判断

| 现实信号 | 先查什么 | 可以怎样开始 |
|---|---|---|
| 每次都想起来，但到了那一刻还是开始不了 | 能力链中最薄弱的一环 | 缩小规模，或只保留启动动作 |
| 锚点每天出现，行为发生却忽高忽低 | 锚点最后动作、地点和频率 | 只重写锚点，不同时换行为 |
| 微小版本已经很稳，不知道何时加量 | 是否经常自然多做 | 增加一个可选扩展，不抬高原基线 |
| 一个愿望下有几个行为都合适 | 每个行为是否能独立形成配方 | 先推进一个，其余留在候选区 |
| 出差、搬家或换班后原配方失效 | 新环境中的提示与能力 | 按新地点重新匹配提示和难度 |
| 旧行为涉及成瘾、进食、自伤或伤人风险 | 安全边界与专业支持 | 联系合格专业人员，不只依赖软件 |

## 10. 在软件里如何保存和回顾

- 核心字段自动保存在本机 SQLite 数据库中。
- 长期习惯的每个微习惯方案都有独立的锚点、庆祝、配方版本、实践和诊断记录。
- 删除包含历史的项目或方案前，软件会先创建完整保护备份。
- 数据管理中可以备份、恢复、导出和导入。
- 默认不需要账号、网络或 AI，个人行为数据不会被自动发送到外部服务。

## 11. 一页术语速查

- **愿望**：想让生活变成的方向。
- **具体行为**：某个人在某个时刻可以实际做出的动作。
- **黄金行为**：有影响、想做且做得到的行为。
- **微行为**：即使动机很低也能完成的极小行为。
- **入门步骤**：只做自然开启更大行为的第一步。
- **锚点**：生活中已经稳定发生、用来提示新行为的动作。
- **庆祝**：在行为完成后立即创造真实成功感的动作。
- **配方**：“在我完成锚点之后，我会做微行为，然后立即庆祝。”
- **诊断顺序**：对期望行为是提示 → 能力 → 动机；对终止行为是先移除提示，再让行为更难，最后才调整动机。

## 12. 最后的使用建议

当你不知道怎么继续时，不必补完所有字段。回到这三个问题：

1. 我真正想要的是什么？
2. 什么行为小到我现在就做得到？
3. 它将在哪个可靠时刻被提示？

然后去试一次。现实结果会告诉你下一版如何设计。
