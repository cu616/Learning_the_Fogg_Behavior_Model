## 维护方式

- 庆祝方式库和微习惯配方库由 `scripts/extract_references.py` 生成，不要手工批量修改。
- 表 9-1 在 PDF 中是图片，`肯定成功方式库.md/json` 是经视觉核验的人工转录文件。
- 修改人工转录内容时，应同时更新 Markdown 和 JSON，并再次对照 PDF 第 328-329 页。
