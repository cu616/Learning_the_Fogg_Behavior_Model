# 《福格行为模型》AI 可检索知识库

本目录由仓库内 `source/福格行为模型.pdf` 转换而来，目标是让读者和后续 AI 能快速搜索、分段阅读，并能按 PDF 物理页码回查原书。PDF、整本全文、分章文件与页级索引均随仓库提供，克隆后无需先执行提取脚本。

## 文件说明

- `福格行为模型-全文.md`：完整文字合订版，保留每一页的页码锚点。
- `chapters/`：按主题拆分的 11 个 Markdown 文件，适合按章加载，避免一次读取全文。
- `page-index.jsonl`：每个 PDF 页面一条 JSON 记录，适合程序检索、RAG 切片或建立向量索引。
- `references/`：附录中的结构化参考库，包括 32 种肯定成功的方式、100 种庆祝方式和 300 个微习惯配方，同时提供 JSON 与 Markdown，供软件作为内置参考数据加载。
- `术语速查.md`：核心概念、方法与诊断顺序的简明索引。
- `图表与流程说明.md`：把文本层无法完整表达的关键图表改写成文字。
- `../scripts/extract_fogg_book.py`：可重复执行的提取脚本。
- `../scripts/extract_references.py`：从附录提取参考库的脚本。

## 推荐给 AI 的阅读顺序

1. 先读 `术语速查.md`，建立概念框架。
2. 涉及图形、流程或产品逻辑时读 `图表与流程说明.md`。
3. 根据问题选择 `chapters/` 中的相关章节。
4. 需要原文语境时，在 `福格行为模型-全文.md` 中搜索关键词并读取相邻页。
5. 需要庆祝方式、配方示例等结构化参考时，读 `references/` 中的 JSON 或 Markdown。
6. 涉及精确引文、表格或图片细节时，依据 `[PDF 第 N 页]`回查 `source/` 中的原始 PDF。

## 快速检索示例

```powershell
# 搜索所有分章文本
rg -n "能力链|缩小规模" knowledge/chapters

# 定位一个 PDF 页面对应的机器索引记录
rg -n '"pdf_page": 110' knowledge/page-index.jsonl

# 搜索微习惯配方及其上下文
rg -n -C 3 "微习惯配方" knowledge/福格行为模型-全文.md
```

## JSONL 字段

每行包含：

- `id`：稳定页面标识，如 `fogg-p110`；
- `source`：来源 PDF；
- `chapter`：所属章节；
- `pdf_page`：PDF 物理页码；
- `text`：该页清理后的文本。

## 使用限制

这是从 PDF 文本层自动提取的检索副本，不是重新校订的电子书。断行、图注、脚注、英文空格和少数特殊字符可能存在误差；图形关系请优先参考 `图表与流程说明.md`，需要精确引用时必须回查原始 PDF。

原书及其生成内容仅应在相应授权范围内存储、学习和分享。仓库所有者负责持续维护上传与分发授权；如果授权状态发生变化，应停止分发相关文件。
