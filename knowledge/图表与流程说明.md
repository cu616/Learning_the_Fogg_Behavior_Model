# 福格行为模型关键图表与流程的文字说明

本文件补充 PDF 中文本提取容易遗漏的图形关系。页码均为 PDF 物理页码。

## 1. 福格行为模型与行动线

参考 PDF 第 45、49、321 页。

- 纵轴是动机：越向上越强。
- 横轴是能力：越向右代表行为越容易做到。
- 图中有一条向右下方弯曲的行动线。
- 行为点位于行动线上方时，提示出现会触发行为。
- 行为点位于行动线下方时，仅仅增加提示通常只会带来忽略、挫败或烦恼。
- 让行为越过行动线有两条路径：提高动机，或让行为更容易；长期设计通常优先选择后者。

## 2. 焦点地图

参考 PDF 第 87-95 页。

焦点地图是一个二维平面：

- 纵向从“低影响行为”到“高影响行为”；
- 横向从“我无法让自己做到”到“我能够让自己做到”。

使用方法：把行为集群中的每个具体行为分别放到地图上。右上区域同时满足“有助于实现愿望”和“我能做到”，这里的少量行为是优先设计的黄金行为。它不是根据流行建议或他人的偏好选行为，而是进行人与行为的匹配。

## 3. 能力链

参考 PDF 第 110-112 页。

能力链由五个相连环节组成：

`时间 → 资金 → 体力 → 脑力 → 日程`

整条链的强度由最薄弱环节决定。诊断时逐项询问：是否有足够时间、资金、体力和脑力，以及该行为是否适合当前日程。找到最弱环节后，可以提升技能、引入工具或资源、缩小行为规模，或改为只做入门步骤。

## 4. 锚点与微习惯配方

参考 PDF 第 144-153、322 页。

配方的时间顺序是：

`既有行为的最后动作（锚点时刻） → 新的微行为 → 即时庆祝`

标准句式是：

`在我完成______之后，我会______。`

有效锚点应当稳定发生、时间位置明确，并与新行为的地点、频率和主题相容。提示不是模糊的“早晨”或“有空时”，而应尽可能精确到某个既有行为的最后动作。

## 5. 行为设计的模型、方法和原则总图

参考 PDF 第 320 页。

总图将知识分成三层：

- 模型：解释行为如何运作，包括 B=MAP、动机与能力的变化、行为集群、自动化程度光谱、行为改变系统方案等。
- 方法：用于设计行为，包括微习惯、行为集群工作表、焦点地图、框架解决法和“容易做”分析等。
- 原则：帮助人们做他们已经想做的事；帮助人们感受成功。

对工具开发而言，模型负责诊断，方法负责交互流程，原则负责约束反馈语气和产品伦理。

## 6. 让行为更容易的流程

参考 PDF 第 324 页。

流程依次检查：

1. 用户是否有能力且愿意接受训练；如果愿意，就通过训练提升技能。
2. 能否引入工具或资源；如果可以，就把它们放入行为发生的情境。
3. 能否通过缩小规模，把行为变成微小行为。
4. 能否找到一个入门步骤，只完成行为的开端。
5. 如果所有路径都不可行，应重新选择行为，而不是继续责备用户。

## 7. 行为改变系统方案

参考 PDF 第 243-265、325-326 页。

系统分为三个阶段：

### 阶段 1：创建新习惯

`明确愿望 → 建立行为集群 → 选出黄金行为 → 让行为容易 → 匹配锚点 → 写配方并选择庆祝 → 演练 → 在生活中试行 → 根据反馈调整`

如果没有执行，区分原因是忘记、太难、不想做或其他障碍，并分别调整提示、能力或行为选择。调整被视为正常迭代。

### 阶段 2：终止旧习惯

`建立坏习惯的行为集群 → 选一个最容易改变的具体行为 → 先处理提示 → 再增加执行难度 → 再处理动机`

提示处理顺序包括移除、规避和忽略；增加难度可从时间、资金、体力、脑力和日程冲突入手。一次处理一个具体行为，成功后再返回行为集群选择下一个。

### 阶段 3：用新习惯替代旧习惯

如果终止流程仍不奏效，就设计一个能占据相同时机、满足相近需要或改变行为路径的新习惯，以它替代旧习惯。
