# 福格行为实验室·孤独摇滚主题版

这是一款把《福格行为模型》变成可操作流程的本地行为设计软件。它不要求你先读完原书，也不靠连续打卡、意志力口号或失败惩罚推动改变。

你可以用它处理三类事情：

- 建立长期习惯，例如开始阅读、恢复运动、改善睡前准备；
- 完成一次性行为，例如提交报销、预约检查、回复重要邮件；
- 减少或终止旧习惯，例如睡前刷手机、无意识打开应用。

界面采用《孤独摇滚！》主题视觉，把乐队排练、分解动作、试错和重新调整的感觉融入行为设计过程。方法和数据功能不依赖网络，Windows 与 Android 均可使用。

## 先下载哪个文件

安装包不保存在源码目录中。当前仓库还没有建立 GitHub Release，因此点击 GitHub 的 “Code → Download ZIP” 下载到的是源代码，不是可以直接安装的软件。

开发电脑上已经生成的文件位于：

    output/packages/
    ├─ 福格行为实验室_0.1.0_x64-setup.exe
    ├─ 福格行为实验室_0.1.0_x64-portable.exe
    ├─ 福格行为实验室_0.1.1_arm64.apk
    └─ 安装说明.md

output/packages/ 已被 Git 忽略，不会随仓库上传。需要让别人从 GitHub 下载时，应把这些文件作为附件上传到本仓库的 [Releases 页面](https://github.com/Praying1213/Learning_the_Fogg_Behavior_Model/releases)，不要直接提交到代码分支。

| 文件 | 适用设备 | 怎么选 |
|---|---|---|
| **福格行为实验室_0.1.0_x64-setup.exe** | Windows 10/11，64 位 | 推荐给普通 Windows 用户；负责安装、开始菜单和卸载入口 |
| **福格行为实验室_0.1.0_x64-portable.exe** | Windows 10/11，64 位 | 不想安装时使用；复制到任意文件夹后直接运行 |
| **福格行为实验室_0.1.1_arm64.apk** | Android 7.0 及以上，ARM64 | 当前手机端新版，修复了窄屏拥挤和右上角不易点击的问题 |

当前源码版本和 Android APK 为 0.1.1；已有的 Windows Setup 与便携版仍为 0.1.0。这不是下载错误，而是两个平台目前的构建版本不同。

## Windows 安装与使用

### Setup 安装版

1. 双击 **福格行为实验室_0.1.0_x64-setup.exe**。
2. 按安装向导完成安装。
3. 从桌面或开始菜单打开“福格行为实验室”。
4. 不再使用时，可在 Windows“已安装的应用”中卸载。

Setup 内含离线 WebView2 组件，因此体积会明显大于便携版。当前 Windows 文件没有商业代码签名证书，系统可能显示“未知发布者”或 SmartScreen 提醒。请确认文件来自你信任的仓库或传输渠道后再运行。

### 便携版

1. 把 **福格行为实验室_0.1.0_x64-portable.exe** 放到一个不会被随手删除的文件夹。
2. 双击即可启动，不需要安装。
3. 可以复制 EXE 到 U 盘或其他目录，但行为数据并不保存在 EXE 旁边，而是保存在 Windows 的应用数据目录。

便携版与 Setup 版使用同一套本地数据。它们的差别主要是有没有安装向导、快捷方式和卸载入口。

## Android 安装与使用

当前 APK 为 **福格行为实验室_0.1.1_arm64.apk**，适用于大多数近年的 Android 手机。

1. 把 APK 发送或复制到手机。
2. 在手机的文件管理器中点开 APK。
3. 如果系统拦截，按照提示临时允许当前文件管理器“安装未知应用”。
4. 安装完成后打开“福格行为实验室·孤独摇滚主题版”。
5. 安装结束后，可以关闭“安装未知应用”权限。

如果出现“无法安装”，先检查：

- Android 版本是否为 7.0 或更高；
- 手机是否为 ARM64 架构；
- 手机上是否已经安装了签名不同的同包名版本；
- 是否留有足够的存储空间。

手机和电脑各自保存一份独立数据，不会自动同步。覆盖安装同一签名的新版本通常会保留数据；卸载 Android 应用会清除它的应用内数据，因此卸载或更换签名前应先导出备份。

## 第一次打开后怎么用

不需要先学习完整理论。先从首页选择与你现在的问题最接近的入口。

### 想让一个行为长期发生

选择“长期习惯设计”。

例如，你想恢复阅读：

1. 写下真正想改善的方向；
2. 列出多种可能行为，不急着承诺；
3. 选出既有帮助、自己又愿意并能够做到的行为；
4. 把它缩小到状态不好时也能开始，例如“读一段”；
5. 接到稳定锚点，例如“把早餐餐具放回去之后”；
6. 选择一个自然、及时的庆祝动作；
7. 在现实中尝试，再根据结果调整。

最终得到的不是一句“每天读书”，而是一条能排练的配方：

> 在我把早餐餐具放回去之后，我会读一段，然后用自己舒服的方式确认：这一拍接上了。

### 只需要把一件事做完

选择“一次性行为”。

例如“提交报销材料”。软件会先帮你明确唯一的下一动作，再按下面的顺序找主要阻力：

1. 提示：开始时刻是否有清楚、及时的信号；
2. 能力：时间、体力、材料、步骤或环境是否让它太难；
3. 动机：这件事是否仍值得做，是否需要取消、委托、延期或重新协商。

每轮只处理最接近现实的一项阻力，然后回到行动，而不是一直分析。

### 想减少一个旧习惯

选择“终止旧习惯”。

先把模糊目标拆成具体、可观察的行为，例如把“少玩手机”改为“上床后反复打开短视频”。接着观察它通常在什么情境出现，再分别处理提示、能力和动机，并设计更容易发生的替代行为。

中断、忘记或调整方案都不是“失败”。它们只是下一轮设计需要使用的信息。

更完整的跟做案例、术语解释和常见情境见 [用户说明书](docs/福格行为实验室-用户说明书.md)。软件内也可从“使用说明”打开离线版本。

## 这款软件有什么特点

### 三类工作流，不只是习惯打卡

长期习惯、一次性行为和终止旧习惯分别使用适合自己的流程，不把所有问题都塞进同一种任务卡片。

### 完整的七步行为设计

长期习惯流程包含愿望、行为探索、黄金行为、微小版本、锚点、庆祝、实践与诊断。行为集群、焦点地图、能力链等工具直接放在需要使用的步骤中。

### 先看现实条件，不责怪自己

行为没有发生时，软件优先检查提示和能力，再检查动机。它不使用连续天数清零、惩罚或羞耻式文案。

### 一次只调整一个主要因素

诊断不会要求同时重做整套方案。先修改最可能影响结果的一处，再带着新版本回到现实验证。

### 多项目、版本与记录

每个行为设计项目独立保存自己的步骤状态、微习惯配方、版本、实践日志和诊断记录。可以同时管理多个方向，也可以暂停、归档或重新开始。

### 本地优先、离线可用

核心流程使用本机 SQLite 数据库，无需注册账号，也不依赖 AI 或网络服务。Windows 和 Android 的数据各自保存在设备上。

### 备份、恢复与迁移

软件提供本地备份、恢复、JSON 导出与导入。换电脑、换手机或卸载应用前，应先导出一份 JSON。

### 孤独摇滚主题界面

人物、配色、舞台与排练元素参与页面构图和引导文案，而不只是把角色图片贴在空白背景上。桌面端和手机端使用同一套行为设计逻辑，并分别适配宽屏与窄屏布局。

## 数据保存在哪里

程序不会把习惯数据自动上传到服务器。

- Windows：数据库由系统放在 com.fogg.lab 对应的应用数据目录中；
- Android：数据库位于应用的私有数据目录，普通文件管理器通常看不到；
- 手动备份：在软件的“数据与隐私”页面创建；
- 跨设备迁移：从旧设备导出 JSON，再在新设备导入。

重要数据不要只依赖应用目录。升级、卸载或迁移设备前，先在“数据与隐私”中导出 JSON，并把文件复制到安全位置。

## 给开发者

### 技术构成

| 部分 | 技术 |
|---|---|
| 应用容器 | Tauri 2 |
| 界面 | React、TypeScript、Vite |
| 本地数据 | Rust、SQLite（rusqlite bundled） |
| 规则诊断 | 本地规则，不调用 AI |
| 桌面目标 | Windows 10/11 x64 |
| 手机目标 | Android 7.0+ ARM64 |

### 本地运行

    cd app
    npm ci
    npm run tauri dev

也可以在 Windows 中运行 app/dev.bat。浏览器界面调试可使用项目既有的 mock 模式，但真实数据读写和备份功能应在 Tauri 应用中验证。

### 构建 Windows

    cd app
    .\build-app.bat

只生成正式离线 EXE，不生成安装器。需要 NSIS Setup 时运行：

    cd app
    .\release.bat

不要直接使用 cargo build --release 代替 Tauri 构建；这样可能遗漏前端产物或保留开发地址。
