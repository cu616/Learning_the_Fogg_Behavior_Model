# 福格行为实验室

本项目围绕《福格行为模型》（B.J. 福格 著）做两件事：

1. **知识库**：把 360 页原著 PDF 转成可检索、可分章阅读的知识库，并整理出结构化参考库。
2. **软件**：开发一款**本地优先**的行为设计桌面软件「福格行为实验室」，既支持七步长期习惯设计，也帮助一次性行为越过行动线。

> 一句话定位：在本地用福格行为模型设计长期微习惯，或通过 P→A→M 循环完成一件明确的一次性行为。

## 软件：福格行为实验室

### 定位与原则

- **本地优先**：无账号、无网络、数据只存本机，核心流程离线可用。
- **工作流优先**：福格七步骤是主骨架，内部工具（行为集群、焦点地图、能力链、锚点、庆祝）都嵌在对应步骤里。
- **实验而非评判**：没有执行时进入诊断，不把用户描述为"失败"；不做连续打卡清零、惩罚或羞耻机制。
- **低负担**：日常记录数秒内完成，详细分析只在需要时展开。

### 技术栈

| 层 | 选型 |
|---|---|
| 桌面容器 | Tauri 2.x |
| 界面 | React + TypeScript + Vite |
| 本地数据库 | SQLite（rusqlite，bundled） |
| 数据模型 | 33 张业务表，INTEGER 主键 + uuid 稳定身份，schema v7 |
| 参考数据 | 前端 import JSON（100 庆祝 / 300 配方 / 32 肯定成功方式） |
| AI | 首版纯规则，不接任何 AI/网络 |

### 功能清单

- **七步工作台**：明确愿望 → 探索行为 → 匹配黄金行为 → 从微习惯开始 → 找到对的提示 → 庆祝成功 → 实践与迭代
- **一次性行为**：快速捕获 → 现在做/卡住/稍后 → P→A→M 按需诊断 → 返回行动，可取消、委托、延期或转为长期习惯
- **终止旧习惯**：改变准备 → 拆解旧习惯 → 布置 P/A/M 对策 → 观察调整 → 设计替代行为
- **多黄金行为**：一个愿望可选择多个黄金行为，每个行为可维护多个独立微习惯分支
- **可视化画布**：行为卡片可拖动并自由调整尺寸；焦点地图使用 −4～4 四象限坐标和醒目的零轴
- **可恢复删除**：长期设计和一次性行为均可删除，删除前自动建立完整保护快照
- **多习惯管理**：新建 / 复制 / 归档 / 状态筛选 / 搜索 / 分组
- **当前行动首页**：跨三类工作流展示最近项目、当前阶段和下一动作，一步回到真实实验
- **零基础使用说明**：软件内置完全离线的方法指南，并提供可独立阅读的完整说明书
- **实践与诊断**：今日快速记录（六种结果）+ 提示→能力→动机 纯规则诊断
- **配方版本**：每次修改生成新版本，实践记录绑定当时版本，可回溯
- **内置与个人参考库**：行为、锚点、庆祝、完整配方和肯定成功方式均可离线浏览，并显式保存到“我的库”
- **数据管理**：备份（自动滚动保留 7 份）/ 恢复 / 导出 / 导入 / 应用锁
- **自动保存**：字段级即时保存，异常退出重启不丢数据

### 运行与打包

```bash
cd app
./dev.bat        # 开发运行（已封装 node + cargo + MSVC 环境）
./build.bat build   # 编译
./build.bat test    # 测试
./build-app.bat  # 只构建正式离线 EXE，不生成安装包
./release.bat    # 打包 Windows 10/11 x64 离线安装包（NSIS + WebView2）
```

发布或覆盖便携 EXE 必须使用 `build-app.bat` 或 `npm run tauri -- build --no-bundle`，不要直接使用 `cargo build --release`；后者可能保留只供开发使用的 `localhost:1420` 地址。

安装包输出：`app/src-tauri/target/release/bundle/nsis/福格行为实验室_0.1.0_x64-setup.exe`

> 构建环境需要 Node.js/npm、Rust stable 和 Visual Studio C++ Build Tools。脚本不再包含开发者个人电脑的绝对路径。

安装包嵌入 WebView2 离线安装程序，目标电脑安装与使用核心功能时不需要联网。当前发布目标为 Windows 10/11 x64；安装包尚未使用商业代码签名证书，Windows 可能显示“未知发布者”。

## 知识库说明

- **全文**：`knowledge/福格行为模型-全文.md`，每页带 `[PDF 第 N 页]` 锚点，可回查原书。
- **分章**：`knowledge/chapters/`，按主题拆成 11 个文件，适合按章加载。
- **检索**：`knowledge/page-index.jsonl`，每页一条 JSON（id/source/chapter/pdf_page/text）。
- **参考库**：`knowledge/references/`，从附录整理的结构化数据，JSON + Markdown 双格式。

提取脚本（可复现）：

```bash
python scripts/extract_fogg_book.py       # 生成全文/分章/索引
python scripts/extract_references.py      # 生成庆祝方式库、微习惯配方库
```

原始 PDF、整本全文、分章文件和页级索引只保存在开发者本机，不上传到源码仓库。需要时请将合法取得的 PDF 放入 `source/` 后重新运行提取脚本。
